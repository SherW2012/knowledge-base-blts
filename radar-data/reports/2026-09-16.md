## 1. Gemini 3.8 Live / Live Extended Thinking 正式 GA：实时语音聊天时后台推理与异步工具调用

官方：https://ai.google.dev/gemini-api/docs/changelog

Google 9 月 15 日发布两款 Live API 的 audio-to-audio 模型。普通 Live 侧重低延迟、交错推理和默认异步函数调用；Extended Thinking 在实时语音会话进行时可后台推理。**这是开发者 Live API 可用，不等于所有 Gemini App 用户自动获得。**

**为什么值得发：** 实时语音 Agent 可以边和用户交流边查资料、调用工具或完成较复杂推理，适合语音助手、客服和实时语音 App。

## 2. Claude for Small Business：43 套现成业务工作流，新增 27 个集成

官方：https://claude.com/blog/claude-for-small-business-launches-new-workflows-integrations-and-training-programs

Anthropic 9 月 15 日推出 43 套小企业工作流与 27 个新集成，包括 Shopify、Salesforce、TikTok、Stripe、Zapier、Zoom 等，覆盖获客、客户沟通、财务、营销等。使用 Claude 付费计划；敏感外发和付款仍需按工作流确认。

**为什么值得发：** 一人公司和小团队能直接复用业务操作模板，接上自己已有的软件，不必先从零搭建一套自动化。

## 3. Kilo Mobile：iOS / Android 上启动远程 Coding Agent、审 PR、看 Diff

官方：https://blog.kilo.ai/p/kilo-mobile-update-run-your-engineering

Kilo 9 月 15 日更新移动 App 并在 Product Hunt 发布：在手机上选 GitHub 仓库、分支并启动云端/远程 Agent，查看会话进度、代码差异、评论与审查 PR。iPhone 可通过 Live Activities 接收进度；Android 使用通知与小组件。**执行环境是云端或连接的远程机器，不是手机本地跑大模型。**

**为什么值得发：** 离开电脑也能布置 Coding 任务、确认代码和继续迭代，不用等到坐回工位。

## 4. Capsule：Show HN 高热，一份文件打包整个网页 App 与 SQLite 数据库

官方：https://withcapsule.app/

9 月 15 日 13:31 UTC 的 Show HN 新项目。Capsule 把 HTML UI、素材和 SQLite 数据封进一个 `.capsule` 文件，支持 AI 生成与修改小应用，macOS/Windows/Linux 有免费播放器，可离线传文件给别人用。Web 版只供预览；iOS/Android **尚未发布**。

**为什么值得发：** Vibe Coding 搭的小工具不想买服务器、部署数据库，也能像发 Word 文档一样分享一个完整应用，收件人安装播放器即可运行。

## 5. Salesforce in Claude beta：37 个销售 Skills，Claude 对话里完成 CRM 查询与回写

官方：https://claude.com/blog/salesforce-in-claude

9 月 15 日 Anthropic 发布 Salesforce in Claude beta；能查询客户、商机、销售管道、准备电话、做预测，用户批准后可写回 Salesforce。当前需 Salesforce 批准组织的 beta 资格及 Claude 付费计划，并非全民可用。

**为什么值得发：** 销售团队可以集中在对话入口处理客户资料、会议准备、商机更新，少在多个 CRM 页面之间切换。

## 6. tiun：把登录、订阅、按量收费、支付税务整合给 AI / SaaS 开发者

官网：https://tiun.io/

9 月 15 日 Product Hunt 上线，把 Auth、用户库、结账、订阅、一次性支付、按量计费、Merchant of Record 整合到一起，并提供 SDK/MCP。基础平台官方标 Free，**但交易、订阅、提现、争议等均有费用**；明细：https://tiun.io/pricing。

**为什么值得发：** AI 做完首个 SaaS 之后，登录与收款不必全自己写；评估时需要把真实手续费算进定价。

## 7. Addy Osmani 的 Agent Skills：25 个工程 Skills，一条命令安装

项目：https://github.com/addyosmani/agent-skills

9 月 16 日 GitHub Trending 快照出现。仓库提供 25 个 Skills 和 `/spec`、`/plan`、`/build`、`/test`、`/review`、`/ship` 等生命周期命令，可 `npx skills add addyosmani/agent-skills` 安装，覆盖 Claude Code、Codex、Cursor 等。今日新鲜度是 Trending，而非仓库今天初次发布。

**为什么值得发：** 可以直接给 Agent 套上成熟工程检查流程，减少每个项目重写 Prompt、漏测试与验收。

## 8. Atlas：Claude Code / Codex 共用记忆，Commit 可回溯 Agent 会话

项目：https://github.com/pacifio/atlas

9 月 16 日 GitHub Trending 榜上出现。Atlas 将代码提交和对应 Agent 会话、Prompt、工具调用、文件改动关联，让 Claude Code、Codex 等在同一个项目共享上下文。Windows、macOS 可用；本地模式无需账号，可离线，MIT 开源。模型费用仍按原工具算。

**为什么值得发：** 同一代码仓在多个 Agent 间切换时，不需要反复解释背景；有问题可从 Commit 查当时 Agent 的操作记录。

## 9. 《极简创业者》变 10 个 Claude Skills：验证想法、MVP、获客、定价

项目：https://github.com/slavingia/skills

9 月 15 日 Product Hunt 出现的公开 Skills 集，涵盖找社区、验证需求、MVP、手动服务、第一批客户、营销、定价、增长等。Claude Code 中通过 `/plugin marketplace add slavingia/skills` 与 `/plugin install minimalist-entrepreneur` 安装。Skill 仓库公开，模型调用不保证零成本。

**为什么值得发：** 想用 AI 做产品卖钱的人，直接拿从验证到第一批客户的行动清单，不用先把所有功能开发完。

## 10. Voiskey：按输入场景修饰语音内容，不再只做逐字转录

产品：https://www.producthunt.com/products/voiskey

9 月 15 日 Product Hunt 上线，支持 iOS、Android、macOS、Windows。它会根据微信聊天、工作邮件、AI Prompt 等场景整理不完整的口语，支持多语言与自定义术语；官方表示免费入门、推出月度 Pro 试用，长期免费额度需再看应用定价。

**为什么值得发：** 可以直接把半成品思路说出来，AI 整理成适合目标输入框的文字，再由用户确认发送。

## 11. OpenResearch：GitHub 上的本地优先 Agent 研究工作台

项目：https://github.com/alphaXiv/OpenResearch

9 月 16 日 GitHub Trending 快照出现；MIT 开源，可把 Claude Code、Codex、OpenCode、Cursor 变成分工研究 Agent，用独立 Git worktree 跑文献、假设、实验和证据归档。macOS 桌面版、Windows beta、Linux CLI；本地使用可选本地模型，但云端模型或托管算力可能收费。

**为什么值得发：** 用 AI 长期做研究，不止拿到一篇报告，还能保留研究过程、不同实验路线及证据，便于复现和继续追踪。
