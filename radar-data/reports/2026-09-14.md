## 1. LLM Wiki：GitHub 今日 +647 Star，文件丢进去以后自己长成一个能被 Claude / Codex 查询的 Wiki

项目：https://github.com/nashsu/llm_wiki

GPLv3 开源，Windows、macOS、Linux 都有预编译版本。它可导入 PDF、Office、EPUB/MOBI、网页、图片等资料，持续生成带来源、互相链接的持久 Wiki，而不是每次提问都重新做一次 RAG；同时提供本地 HTTP API、MCP Server，以及可一条命令装进 Claude Code / Codex 的 Skill。

产品：https://vehla.app/
