## 2. Geiger：一个命令查清本机所有 AI Agent / MCP / 插件到底能碰什么

项目：https://github.com/Atomburstofficial/geiger

本轮 Show HN 新信号。MIT 开源，运行 `npx geiger-scan` 即可，只读、无账号、无遥测。会盘点 Claude Code、Codex、Gemini CLI、Cursor/Windsurf、MCP Server、浏览器 AI 扩展、VS Code / JetBrains 插件等，并标出执行命令、持有密钥、广泛文件访问和联网能力以及证据路径。

**为什么值得发：** Agent 和 MCP 装多以后，大部分人根本记不清谁能访问什么。它把权限体检压缩成一条命令，不需要先学安全理论。

## 3. Harden：Coding Agent 真要执行危险动作之前，先过一道本地安全闸门

产品：https://harden.run/

Product Hunt 9 月 9 日高位新品。它在命令、文件修改、工具调用和外发请求真正执行前本地检查，遇到密钥泄露、数据外传或破坏性操作可以只拦下那一步，其他任务继续。个人开发者免费、无需账号。需要明确：核心安全模型和算法是专有的，并非开源。

**为什么值得发：** 长时间后台跑 Agent 时最怕一个不可逆动作。它不是给 Agent 加新能力，而是在真正执行前多一道刹车。
