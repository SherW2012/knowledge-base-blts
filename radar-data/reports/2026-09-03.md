## 最终精选 8 条

### 1. 10 万 Star 的“山顶洞人” Skill：让 Claude / Codex 少说废话，直接省 Token

Caveman 可装进 Claude Code、Codex、Cursor、Gemini CLI 等 30+ Agent。它最直观的玩法就是逼 Agent 把解释压短。项目自己的 10 题测试里，平均输出从 1214 tokens 降到 294，约少 65%；项目也明确提醒，全会话真实省幅会低于这个数字，短任务甚至可能因为规则开销不划算。

**为什么值得发：** 一条命令能试，用户不用理解上下文工程就知道“少废话、快一点、少花 token”有什么用。

项目：https://github.com/JuliusBrussee/caveman

### 2. 开源版 ElevenLabs：3 秒克隆声音，646 种语言，全在本地跑

VoiceStudio 把声音克隆、声音设计、视频配音、听写、转录和有声书放进一个开源桌面应用。官方称短音频通常 3 秒左右即可用于克隆，支持 646 种语言；本轮 GitHub Trending 继续增长，仓库也在窗口内更新。

**为什么值得发：** 视频配音和声音克隆是普通创作者马上能理解的需求，而且不用先买云端点数，也不用把声音上传出去。

项目：https://github.com/debpalash/VoiceStudio

### 3. Chrome 里右键就能查 Deepfake

deepeye 把 AI / Deepfake 检测做进 Chrome、iOS 和 WhatsApp。右键图片、选中文本或转发可疑消息都可以检查，官方还展示了克隆声音检测；免费档每月 10 次扫描。

**为什么值得发：** “这张图 / 这个声音到底是不是真的”已经是日常问题，不需要给用户解释技术原理。

产品：https://www.deepidv.com/deepeye

### 4. PDF / Word / 网页先转 Markdown，再扔给 AI

anyto.md 能把 URL、PDF、Office 文件、HTML 和图片转成适合模型读取的 Markdown，提供 5 次免费转换。核心用法非常简单：先去掉复杂格式，再把同一份 Markdown 重复用于 ChatGPT、Claude、Agent 或 RAG。

**为什么值得发：** 这是一个用户今天就能带走的 AI 文件处理习惯，尤其适合长 PDF 和 Word。

产品：https://anyto.md/

### 5. Gemini 3.8 Flash 上线：更强，但当前价格不涨

Google 9 月 2 日正式发布 Gemini 3.8 Flash，称它是目前最强的 Flash 推理 / 编程模型，同时保持 3.7 Flash 的当前价格：$0.75 / 百万输入 tokens，$3.75 / 百万输出 tokens。它已经进入 Gemini App、Google Search AI Mode、Google Sheets，并向 Google AI Pro / Ultra 用户开放。

**为什么值得发：** 不是 benchmark 新闻；用户今天就能换到新模型，而且当前使用价格没有跟着涨。

官方：https://blog.google/innovation-and-ai/models-and-research/gemini-models/3-8-flash-and-3-8-flash-cyber/

### 6. 有人在重新做 Siri：看环境、看日程，再替你操作 App

Touchy 是新上线的 iOS 语音助手。官方示例包括检查购物清单、根据下一个日程叫车、做饭时看着食材给帮助。发布后团队还说访问量触发了上游 rate limit。

**为什么值得发：** “少在几个 App 之间来回切，直接说我要做什么”是普通人能直接感受到的 Agent 场景。

产品：https://www.producthunt.com/products/touchy-3

### 7. Claude / Codex 和人一起画设计稿：Doop 多人 + 多 Agent 同画布

Doop 让人和 Claude Code、Codex 等 Agent 在同一张无限画布里实时设计。Agent 的 Frame 会边做边出现，你可以直接留言让它修改，不同 Agent 还能共享画布中的设计记忆。浏览器和 macOS 可用，Beta 免费。

**为什么值得发：** “多 Agent 协作”在这里不再是抽象概念，用户能直接看到几个 AI 在同一张设计稿里工作。

产品：https://doop.design/

### 8. Mac 本地语音输入：听写、会议、YouTube 转录，一次买断

Kekoso 是本轮 Show HN 新项目。它能在 Mail、Slack、Cursor、浏览器等任意输入框直接听写，也能本地转录音视频和有权限的 YouTube 链接，并把通话双方分轨转成文字。识别不离开 Mac；$29 一次买断，7 天试用。

**为什么值得发：** 大量打字、会议记录、录音转文字都是高频需求，“不订阅、不上传”也非常好理解。

产品：https://kekoso.app/
