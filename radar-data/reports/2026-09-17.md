## 2. Google Home 正式开放 MCP：Claude / OpenClaw 可以查询和操作智能家居

一手开发者文档：https://developers.home.google.com/mcp/home

官方更新日志：https://support.google.com/chromecast/answer/15962877?hl=en

Google 9 月 16 日宣布 Home MCP 开始 early access。Agent 可读房间与设备、当前状态、事件历史，并执行受限命令；能查摄像头和历史数据，**并非直接把 Gemini 语音助手替换成 Claude**。第一批仅面向美国英语 Google Home Premium Advanced（**$20/月**）订阅者，需 Google Cloud 项目与 OAuth 授权，分批开放，敏感操作如开锁受禁止；外部 Agent 仍可能误操作。

**读者能拿走：** 家居设备第一次有了标准 MCP 入口，能把家庭传感器和其他 Agent 工作流接起来，但国内用户目前不能照做。选题：**Claude/OpenClaw 开始能操控真实家居了：Google Home MCP 的权限和限制。**

## 4. 腾讯 BrowserSkill：让 Coding Agent 操作真实已登录浏览器，却不抢你的工作窗口

仓库：https://github.com/Tencent/BrowserSkill

本轮新增热度显著，项目为 **MIT**，安装本地 `bsk` CLI 和 Chrome/Edge 扩展后，可把已登录浏览器交给 Codex、Claude Code、Cursor、OpenClaw 等执行任务。Agent 工作在独立可见窗口；若需操作你正在用的标签页，默认申请借用、用完归还，登录/验证码/人类确认可以人工接管。支持 Windows/macOS/Linux；Firefox 仍在计划中，**不是零配置、也不是把整个浏览器无条件交给 AI**。

**读者能拿走：** 让 Agent 复用已登录的 X、后台和办公网站，不用另外造测试账号。选题：**腾讯这个 Skill 解决了最烦的网页自动化问题：AI 办事，你照样用自己的浏览器。**

## 5. Hypit：把参考视频拆成可改的完整剪辑流水线，再批量产出变体

仓库：https://github.com/hypit-ai/hypit

9 月 16 日新 release v0.1.13；安装 Skill `npx skills add hypit-ai/hypit -g`，允许你拿**有授权的参考视频**或自己描述的创意生成完整视频工作流：字幕、画面、B-roll、动画与语音对齐等结构可复用替换。工具核心免费，但 Coding Agent、第三方视频图像模型等仍可能收费。**许可是附加限制的修改版 Apache 2.0，而非标准 Apache 开源：未经授权不得多租户 SaaS 化或商业转售程序；成品还须遵守原素材和模型条款。**

**读者能拿走：** 视频不用每条重剪，先完成一个可修改模板再替换文案素材。选题：**把一条爆款视频变成“可编程的剪辑模板”，下次改文字和镜头就能产出新版本。**
