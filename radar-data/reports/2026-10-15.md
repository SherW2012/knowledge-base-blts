### 1. Specreel：把产品测试记录变成会随版本更新的演示

推荐指数：90/100｜产品演示与内容创作。

进入10月14日PH发布榜。开源CLI把Playwright trace.zip渲染为可分享演示、单文件画廊或MP4；接入CI后，每次测试通过都能重新生成。Cloud也提供粘贴网址、发现演示流程的入口。

**能拿走什么**：产品按钮和页面改动后，可用同一条真实操作流程重建演示，减少教程录屏与当前界面不一致；适合已经有端到端测试的独立产品。

**上手路径**

1. 已有Playwright测试时打开trace记录与screenshots，确保产出包含画面的trace.zip。
2. pip install specreel；运行specreel path/to/trace.zip -o out，生成自包含demo.html。批量流程可用specreel test-results/ -o site/ --bundle。
3. 需要MP4时安装specreel[mp4]并加--mp4；没有测试可从Cloud粘贴自己的产品网址，或用specreel recommend <url>生成流程脚本。

**费用与条件**：CLI采用AGPL-3.0，免费本地运行；默认字幕按操作记录生成，不调用AI。AI改写字幕需自备Anthropic Key并另付调用费。Cloud免费1个项目；前14天含Team试用，Team当前39美元/月，定时检查与提醒属于Team，不能写成永久免费自动巡检。MP4额外依赖见官方安装说明。

**时间证据**：Product Hunt的2026-10-14日榜列出Specreel。该榜单日从北京时间10月14日15:00起，本轮抓取时已出现，处于滚动24小时窗口；按PH发布榜事件记到日，不虚构首发分钟。

**选题切口**：产品刚改了一个按钮，介绍视频又得重录？先看看测试里已经录下了什么。

### 2. TokenTab：把Claude Code、Codex和Gemini CLI的用量摊开看

推荐指数：89/100｜Agent用量与成本。

本轮Trendshift Today第4项。读取本地会话日志，按模型、项目、日期和活动汇总Token与估算费用，提供终端表格及本地网页看板；不需要账号或API Key。

**能拿走什么**：同时使用多个Coding Agent时，可以查明哪个项目、哪类任务消耗最多，再挑具体会话检查上下文、模型选择和反复重试。

**上手路径**

1. 准备Python环境，运行git clone https://github.com/yakuikai/tokentab，然后进入tokentab目录并执行pip install .。
2. 运行python cli.py -today查看今天；python cli.py -web打开本地看板，默认地址http://localhost:4747。
3. 先按项目和模型定位高用量，再回原始会话看原因；活动分类只作为线索，不直接下效率结论。

**费用与条件**：MIT免费，本地读取现有日志，无额外模型调用。价格表由项目人工维护，费用是按Token单价估算，不是订阅账单或剩余额度；未知模型显示$0.00不代表免费。Cursor目前只有未完成的占位适配，不能写成已支持。

### 3. daily.dev for agents：让AI按你的技术兴趣筛文章和讨论

推荐指数：88/100｜信息筛选与MCP。

进入10月14日PH发布榜。官方远程MCP可读取个性化信息流、搜索文章与评论、访问书签；Claude Code、Cursor、Codex等可连接，支持通过daily.dev账号登录授权。

**能拿走什么**：围绕一个选题，让Agent先筛少量相关资料、列出原链接和评论里的争议点，再决定读哪篇；把泛泛“总结今日AI新闻”变成有筛选标准的资料清单。

**上手路径**

1. Claude Code运行claude mcp add --transport http daily.dev https://api.daily.dev/mcp，再在会话输入/mcp完成登录；其他客户端按官方文档配置同一URL。
2. 第一次只读信息流即可，OAuth授权页可以拒绝write权限；无需为了查资料开放收藏或改筛选规则。
3. 给出具体任务：只找与我的技术栈相关、过去24小时出现的3篇实操文章；每篇保留原链接、一个可执行步骤和一个使用限制，不足3篇就少给。

**费用与条件**：MCP连接本身免费，免费账号每月200次API请求；每次工具调用计1次，MCP与个人Token共用额度。Plus提高额度，所用AI客户端或模型费用另算。当前仍为Beta、逐步开放，不能保证所有账号立刻可接入。文章详情与社区讨论也不能代替阅读原文核验。

### 4. xtool：用Windows或Linux构建并装上自己的iOS App

推荐指数：86/100｜跨平台开发与个人App。

本轮GitHub原生日榜快照显示+1,502 stars today。可将SwiftPM项目构建为iOS App，并完成签名、安装和设备操作；Windows通过WSL使用，Linux与macOS也有官方路径。

**能拿走什么**：只有Windows电脑但想做一个自己用的iPhone小工具时，可以从SwiftPM模板走到真机运行；适合先完成最小原型，再判断后续开发投入。

**上手路径**

1. Windows先准备WSL与USB透传；按官方文档安装Swift工具链和usbmuxd，确认WSL能识别iPhone。
2. 从Apple官方开发者下载页获取文档要求的Xcode.xip，再安装对应架构的xtool AppImage并运行xtool setup，配置账号和SDK。
3. 运行xtool new创建模板，进入项目运行xtool dev，在手机完成配对、开发者模式和证书信任；先把默认页面跑通，再加实际功能。

**费用与条件**：xtool本身MIT免费，但仍需Apple账号、从官方获取的Xcode SDK与真机；Windows不是原生双击即用，需WSL/USB透传。API Key登录路径要求付费开发者会员，密码路径支持普通Apple ID但依赖私有接口。本文只验证SwiftPM构建与真机安装能力，不承诺完整替代Xcode、任意工程兼容或免费App Store上架。

**时间证据**：2026-10-15优先读取GitHub Trending Daily原生列表，xtool快照为+1,502 stars today。事件是今日热度观察；项目并非今日首次发布。安装条件回仓库当前官方文档逐项核验。

### 5. Petal：把同事共享的窗口直接摆到自己桌面上

推荐指数：86/100｜远程协作与屏幕共享。

本轮Show HN出现Petal。支持同时共享多个窗口，每个远端窗口在接收者桌面上独立移动、缩放，可显示指针、临时画线，并在授权后远程操作；提供macOS、Windows客户端下载和浏览器加入入口。

**能拿走什么**：一起排查网页问题时，可以把同事的浏览器窗口放在自己的编辑器旁，直接指到出错位置；不用来回说“再往下一点、点左边那个”。

**上手路径**

1. 从官网安装客户端；macOS需要13或更新版本，Windows当前为早期版本。
2. 创建固定房间，邀请对方加入；先只共享需要讨论的浏览器或编辑器窗口，把远端窗口摆到自己的工作区旁边。
3. 先用指针和画线说明问题，需要代操作时再由共享者批准控制请求；未装客户端的人可以通过浏览器邀请入口加入。

**费用与条件**：Apache-2.0开源，官网当前标注免费；自建LiveKit后端需承担服务器成本。项目尚未到1.0，远程控制仍早期；官方明确Windows功能不完整、有Bug且安装包尚无Authenticode签名，macOS更成熟。Linux桌面端仍在计划中。可选Gemini窗口聊天默认关闭，不属于免费无限模型额度。
