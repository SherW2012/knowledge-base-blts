## 1. OpenAI DevDay：Dots 常驻云端干活，GPT-6.1 Sol 降低 Agent 成本

**事件：9月29日发布｜推荐指数 97**

Dots 有自己的云电脑，可在授权范围内处理长期任务，接收反馈并持续协作。GPT-6.1 Sol 的 API 标准输入/输出为每百万 token **2/10 美元**，缓存输入 **0.10 美元**，适合比较重复上下文较多的工作流成本。

Sol 已进入 **Work、Codex 和 API**，不要写成普通 Chat 全面开放。Dots 向符合地区条件的 Pro、Business Premium 开放，Enterprise/Edu/Healthcare 测试需管理员开启；套餐与地区条件不能省略。

**读者能拿走什么：** 常驻处理工作、在手机继续云端任务、降低调用成本，而不是只记住一批新产品名。

**选题角度：**「ChatGPT 不只是等你发问了：Dots 有自己的云电脑」「GPT-6.1 Sol 标准单价只有 Astra 的五分之一，先算常用工作流的账」。

来源：[DevDay 官方总览](https://openai.com/index/devday-2026-recap/) · [Dots 官方介绍](https://openai.com/index/introducing-dots/) · [Sol 官方定价与范围](https://openai.com/index/introducing-gpt-6-1-sol/)

## 2. Gemini 4 Argon：为什么还不能用，优惠定价是多少？

**事件：9月30日发布｜推荐指数 89**

Argon 面向长流程编程、专业工作与网络防御。当前逐步开放给 **Fairwind 可信网络防御伙伴**，尚未全面开放给消费者。官方列出的入门优惠价为每百万 token 输入/输出 **2/10 美元**，优惠期后是 **4/20 美元**；缓存输入优惠95%。

另一个容易写错的细节：**1M 是输出 token 上限，不是上下文长度。**

**读者能拿走什么：** 看清实际开放范围与价格，判断何时值得尝试，不把发布公告误解为自己的账号立刻可用。

**选题角度：**「Gemini 4 已官宣，为什么你的模型列表里还没有？」「Argon 的 2/10 美元是优惠价，不是永久价格」。

来源：[Google 官方公告及定价脚注](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-argon/)

## 3. Cloudflare Clef：Agent 的快速判断，不必每次都写长篇

**事件：10月1日发布｜推荐指数 94**

Clef 与 Clef-flash 输出有限选项及概率，可用于工单分类、请求路由和选择下一步动作。它们兼容 Jev API，支持图像输入与64K上下文，权重采用 Apache-2.0，同时提供 Workers AI 托管入口。

**使用入口与成本：** 可运行公开权重或调用 Workers AI；本地算力和云端调用都不是零成本。强化学习微调平台的自助开放不能当成已经普及。

**读者能拿走什么：** 对已经在做 Jev 分类、路由实验的人，这是一条可以比较的公开权重路线，不必重写整个应用。

**选题角度：**「Jev 之后，Cloudflare 也把决策模型开源了」「该不该转人工？这种问题不必每次生成一大段回答」。

来源：[Cloudflare 官方发布](https://blog.cloudflare.com/clef-decision-models/) · [Cloudflare 模型入口](https://huggingface.co/Cloudflare)

## 4. Meta Muse Gadgets：把 ESP32 和树莓派接到 AI 助手上

**事件：10月2日发布｜推荐指数 92**

Meta 公开 ESP32 与 Linux 设备 SDK/固件，让屏幕、按钮、传感器和执行器连接到 Muse。树莓派或兼容 Linux 设备也能成为入口。

**使用条件：** 需要自己的设备、SDK token，并在 Muse 手机 App 开启开发者模式后配对。SDK 主体为 Apache-2.0；开放的是设备 SDK，不是整个 Muse 模型，也不意味着云服务或硬件免费。

**读者能拿走什么：** 可以动手做桌面助手、家庭控制或硬件小项目，直接展示 AI 与现实设备的交互。

**选题角度：**「Meta 让你自己做 AI 硬件：ESP32 和树莓派都能接」「开源的是设备 SDK，不是整个 Muse 模型」。

来源：[Meta 官方 Muse Gadgets SDK](https://github.com/facebookincubator/muse-gadget-sdk)

## 5. AIHOT：把热点站引擎改成你的垂直行业雷达

**事件：本周热度，非今天首发｜推荐指数 94**

Trendshift 周榜显示 AIHOT 本周约新增5,000 Star。当前公开引擎包含采集、独立双评分、事件聚簇、摘要、日报/周报及 RSS/API/MCP 出口，信源与筛选 Prompt 可以替换。

**当前版本边界：** 仓库只有18个示范信源，不含线上真实运营信源和数据；最新 README 明确模型榜、Codex重置监控等 AI 专属模块留在线上站，不沿用旧版“所有模块都公开”的说法。运行需要 Docker 与模型 API；名称和 Logo 不应照搬。

**读者能拿走什么：** 基于自己的行业信源和判断做垂直情报站，不必从零编写采集、聚类和成刊流程。

**选题角度：**「卡兹克把热点站的引擎给了出来，真正要换的是你的行业判断」「做垂直情报站，先研究筛选标准而不是只抄界面」。

来源：[AIHOT 当前 README](https://github.com/KKKKhazix/AIHOT) · [Trendshift 周榜](https://trendshift.io/weekly)

## 6. OpenDots：自己搭一个有电脑、语音和 Slack 入口的常驻 Agent 工作台

**事件：本轮榜单热度，非首次发布日期｜推荐指数 91**

CopilotKit 的 OpenDots 是 MIT 许可的早期模板，包含专属 Agent、文档空间、人工审批卡片、独立电脑、语音和 Slack 入口。它与 OpenAI 官方 Dots 是不同项目。

**使用条件：** 不是现成免费托管服务。完整使用需要配置模型、Intelligence/Threads、电脑服务；语音和 Slack 分别需要相应连接。启动页面不等于全部功能已接通。

**读者能拿走什么：** 一套常驻 Agent 产品模板，可直接研究任务、页面、权限、电脑和人工确认怎样组织。

**选题角度：**「Dots 上线后，开源版工作台模板也来了」「一个 Agent 一台电脑，还能让你在写入前点批准」。

来源：[CopilotKit OpenDots](https://github.com/CopilotKit/OpenDots) · [Trendshift 日榜](https://trendshift.io/)

## 7. image-blaster：一张图拆出 3D 场景、物件模型和环境音

**事件：本轮榜单热度，非首次发布日期｜推荐指数 92**

image-blaster 用 Claude Skills 串联 World Labs 与 FAL，将单张图片转成静态场景 Gaussian splat、独立 GLB/OBJ 物件和 MP3 环境音，可继续接入 Blender、游戏引擎或 Three.js。

**使用条件：** 需要外部 API Key 和生成费用。本轮没有取得许可证正文，因此只称为公开项目，不等同于可任意商用的标准开源项目；作者的分钟级演示时间也不作为保证。

**读者能拿走什么：** 从一张效果图进一步得到可以探索的场景和可复用资产，适合做生成前后的直观对比。

**选题角度：**「一张图片，拆成能逛的3D场景和能移动的物件」「AI 生图之后，下一步是把图片变成可用资产」。

来源：[项目 README](https://github.com/neilsonnn/image-blaster) · [Trendshift 日榜](https://trendshift.io/)

## 8. Pexo：产品介绍视频不只一键生成，还能逐段修改

Pexo 位列当日 Product Hunt 日榜第一，主打可精修的产品发布视频。可以从产品链接、文档和素材组织脚本、分镜、画面、声音及字幕，再通过对话或局部反馈修改片段。

## 9. Claude Sonnet 5.5：日常 Coding 更快，成本按实际设置比较

**事件：9月28日发布｜推荐指数 94**

Sonnet 5.5 面向编程、文档、演示文稿与表格等工作。官方称输出速度比 Sonnet 5 提升30%以上，API 标准输入/输出仍为每百万 token **2/10 美元**。

更合理的对比方式是拿同一任务、相同验收标准比较：任务成本取决于推理档位和 token 使用量，不是每个任务都比 Opus 便宜。复杂、开放式工作仍是 Opus 的重点。

**读者能拿走什么：** 用自己的修 bug、改页面、整理文档任务决定默认模型，不仅凭排行榜切换。

**选题角度：**「日常修 bug，要不要把默认模型换成 Sonnet 5.5？」「单价没变不代表任务成本相同，先看推理档位」。

来源：[Anthropic 官方 Sonnet 5.5 公告](https://www.anthropic.com/claude-sonnet-5-5)

## 10. ChatGPT Finances 扩到美国 Free/Go：免费用户也能分析真实账单

**事件：10月2日扩围，非功能首发｜推荐指数 87**

Finances 开始向美国 Free、Go 用户逐步开放，覆盖 Web、iOS、Android。连接金融账户后可分析支出、账单与投资信息，是否连接由用户选择。

这是读取与分析入口，不会代转账、付款或执行交易；美国开放不能写成中国大陆或全球全面开放。

**读者能拿走什么：** 符合地区条件的免费用户，可以基于账户数据查找遗忘订阅、看懂钱花在哪里。

**选题角度：**「ChatGPT 查账单这件事，开始向免费用户开放了」「不是自动替你理财，而是先帮你看懂真实支出」。

来源：[OpenAI 10月2日更新日志](https://help.openai.com/en/articles/6825453-chatgpt-release-notes) · [Finances 功能与范围](https://help.openai.com/en/articles/20001222-finances-in-chatgpt)
