## 6. OpenAI 自己公布 Agent 用法：研究团队现在每 1 个人类工作日，背后跑 3.1 个 Agent 工作日

- 链接：https://openai.com/index/research-acceleration-view-inside-openai/
- 时间：2026-09-06
- 分类：Agent 工作流 / OpenAI / 效率
- 雷达分：95
- 摘要：OpenAI 9 月 6 日披露内部研究团队的 Agent 使用数据：到 8 月中旬，研究组织每 1 个 8 小时人类工作日对应约 3.1 个 Agent 工作日；中位数研究员每天按 API 价使用超过 $600 推理，90 分位超过 $7,000。OpenAI 还称已达到“自动研究实习生”里程碑，可在人工指导下完成原本熟练研究员需要几天的明确任务；但复杂任务仍需要大量人工干预。
- 为什么值得发：真正可以拿走的不是“OpenAI 又宣布一个宏大目标”，而是一个非常具体的 Agent 工作方式：并行开多个 Agent，把编码、实验、排障这些长任务放到后台跑，人负责方向、判断和中途纠偏。
- 角度：
  - OpenAI 自己怎么用 Agent？答案不是一个聊天框：1 个研究员工作日背后已经跑 3.1 个 Agent 工作日
  - Agent Harness 最值得抄的不是模型配置，而是并行工作方式：OpenAI 内部越来越多人同时跑 4 个以上 Agent
