## 1. VoiceStudio：完全本地的 ElevenLabs 替代，克隆、配音、听写、转录和有声书放进一个 App

项目：https://github.com/debpalash/VoiceStudio

本轮 GitHub Trending 继续明显爆发，当前跟踪快照约 +2,600 stars today。AGPL-3.0 开源，整合 16 个 TTS、11 个 ASR 与 646 语言目录，支持短音频零样本声音克隆、声音设计、视频配音、系统级听写、转录和长篇有声书。macOS Apple Silicon、Windows 10/11、Linux 都有预编译包；核心本地流程无需账号、API Key、订阅或用量计费。项目仍处于 active beta，下载模型各自受上游许可证约束。

**为什么值得发：** 做短视频、播客、旁白、采访转录或多语言内容的人，可以把原本需要多个云服务的语音工作流直接搬到自己电脑上，先下载 App 就能试。

## 2. Agent Reach：一句话给 Claude Code / Cursor 装上 X、Reddit、YouTube、小红书、B站和全网搜索

项目：https://github.com/Panniantong/Agent-Reach

MIT 开源，本轮 Trending 快照约 +640 stars today。它替 Agent 选择、安装和维护现成互联网工具，让任何能跑命令行的 Agent 获得网页阅读、YouTube 字幕、RSS、GitHub，以及配置后的 X、Reddit、小红书、B站、Instagram、LinkedIn 等能力。网页、YouTube、RSS 等可零配置；部分社交平台需要用户自己的登录态或 Cookie，服务器场景可能需要代理。

**为什么值得发：** 很多 Agent 的真实瓶颈不是模型不够聪明，而是平台读不到、搜不了。这个项目把零散接入方式变成一套能安装、能体检、后端失效还能持续替换的工具，尤其适合内容调研与竞品搜索。

## 3. Oats：Product Hunt 第 5，免费开源、不要会议机器人，还能完全离线转录和总结

项目：https://github.com/ariso-ai/oats

Oats 在 Product Hunt 9 月 14 日榜单获得第 5 名，当前约 230 upvotes、68 comments。MIT 开源，菜单栏一键录音，自动转录、区分说话人并生成 Markdown 笔记，不需要让 bot 加入会议。可以用免费的 Ariso 云端，也可以下载模型后切到 100% 本地离线模式；本地模式无需登录，音频、转录和笔记不离开设备。macOS 14+ Apple Silicon 正式支持；Windows 11 当前为 release preview。

**为什么值得发：** 会议记录产品常见的机器人进会、订阅费和隐私问题，它一次绕开了三个。敏感会议直接切本地模式即可。

## 4. Sunk Cost：买 5090 / Mac Studio 跑本地模型之前，先算到底几年回本

产品：https://sunkcost.ai/

本轮刚登上 Show HN，扫描时约 42 points、78 comments。填写机器价格、显存/内存、功耗、token 用量、上下文需求、电价和 API 价格，它会计算本地跑模型相比继续买 API 大约多久回本，同时列出这台机器能装下哪些模型。没有实测数据时会用内存带宽等参数估算速度并明确标注；模型能力评级是基于公开 benchmark 的粗粒度判断。

**为什么值得发：** 与其先问“本地模型买什么机器”，不如先问“我的用量值得买吗”。它把一次性设备成本和持续 API 账单放到一张表里，买硬件前一分钟就能排除明显不划算的方案。

## 5. OpenCodeReview：阿里把内部 AI Code Review 工具开源，一条命令检查改动

项目：https://github.com/alibaba/open-code-review

Apache-2.0 开源，本轮 Trending 快照约 +443 stars today，且本轮窗口内继续更新。它把确定性的文件选择、规则匹配、定位和反思模块与 LLM Agent 结合，支持 staged/unstaged 改动、分支范围、单 commit 与整个目录扫描，输出精确到行的审查意见。可 npm 全局安装，也能作为 Agent Skill 使用。默认需要配置 OpenAI/Anthropic 兼容模型端点，因此模型调用可能产生费用；delegation mode 可把执行交给已有 Coding Agent。

**为什么值得发：** 通用 Coding Agent 直接做 Review 容易漏文件、行号漂移或输出噪音。这个工具把审查步骤做成固定 CLI 工作流，可以在提交前或 CI 里多跑一道检查。
