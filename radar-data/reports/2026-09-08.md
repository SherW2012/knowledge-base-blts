**可用角度：**
- X 新分成今天开始滚动开放：最关键的一句是“有真实观点的评论和分析也算原创”

## 2. Coding Agent 的 Skill 可以自己长出来了：ZeroShot 会盯着你反复纠正什么，再自动生成可审阅 Skill

- 链接：https://tryzeroshot.com/
- 分类：Agent Harness / Skill / AI Coding
- 发布时间：2026-09-07
- 雷达分：99

ZeroShot 在本轮 Show HN 出现。它会本地记录 Claude Code、Codex、Cursor、Pi、OMP 等编码 Agent 的会话，找出反复出现的 retry、纠正、缺上下文等摩擦；同一类问题跨会话重复出现后，系统会让本地 Agent 草拟一个可复用 Skill。个人本地版免费、不要求账号；团队版还会结合 PR 评论和代码专家贡献记录。

**为什么值得发：** 这正好解决“Skill 靠人手写、写完又没人维护”的问题。你不需要提前猜应该写什么规则，先正常用 Agent，系统从你真实踩过的坑里提炼 Skill，再由你 review。

**可用角度：**
- 以后 Skill 可能不是你想出来的，而是 Agent 从你骂它的历史里自己长出来
- 一个很实用的 Harness 思路：把每次纠正 Agent 的话，自动沉淀成下一次能复用的 Skill

## 3. 看 AI 写的几百行 PR 不用硬啃 diff 了：PR Lens 直接给每个 PR 画一张会动的架构图

- 链接：https://www.producthunt.com/products/coldtea
- 分类：AI Coding / 可视化 / 开源 Skill
- 发布时间：2026-09-07
- 雷达分：98

PR Lens by Coldtea.ai 在 Product Hunt 9 月 7 日拿到日榜第一。它会为代码库和每个 Pull Request 生成动态架构图与数据流图，把新增、删除和变化用可视化方式展示。开源 MIT，可作为 GitHub Action、CLI 或 coding-agent Skill 使用；官方给出的 Skill 安装方式是 `npx skills add coldteadotai/pr-lens`。

**为什么值得发：** Vibe Coding 后最容易失控的不是代码写不出来，而是你逐渐不知道 Agent 到底改了什么。PR Lens 把“先理解系统变化，再读关键 diff”变成一个很直观的工作流。

**可用角度：**
- AI 一次给你改 30 个文件，先别读 diff：让它自己画一张“这次到底改了什么”的动态图
- Archify 之后又来了一个更适合 PR 的玩法：每次 Agent 提交代码，自动附一张架构变化图

## 4. 提词器终于不用追着固定速度念了：Scriptly 会听你说到哪，字幕就自己滚到哪

- 链接：https://www.producthunt.com/products/sciptly
- 分类：AI 工具 / 内容创作 / iOS
- 发布时间：2026-09-07
- 雷达分：97

Scriptly 是 iOS 的语音跟随提词器，9 月 7 日在 Product Hunt 排名第二。它会根据你实际说出的内容实时滚动脚本；如果临场加一句脚本里没有的话，页面会停住，等你重新回到原稿再继续。当前 TestFlight 公测免费，内容本地保存。

**为什么值得发：** 拍短视频最常见的问题就是固定速度提词器逼你配合机器。这个工具反过来让提词器跟着人走，创作者可以自然停顿、临场发挥，不用一边说一边手动拖稿。

**可用角度：**
- 录口播最烦的提词器问题，有人终于做对了：不是你追字幕，是字幕追你
- 你临场加一句它不会乱滚，等你回到稿子再继续：这个语音提词器很适合短视频博主

## 5. 每天手动看数据可以省了：给 AI Analyst 一句话 + 时间表，它到点自己分析完发到 Slack / 邮箱

- 链接：https://www.producthunt.com/products/databox
- 分类：AI Agent / 数据分析 / 自动化
- 发布时间：2026-09-07
- 雷达分：97

Databox 推出 Routines：给 AI Analyst 一个分析提示词和执行频率，它会按时读取实时数据、完成分析并把结果通过邮件、Slack 或应用内通知送出来；历史运行会保存，还能继续追问。用户也可以把自己的分析方式保存成 Skill 后再定时运行。

**为什么值得发：** 很多运营、独立开发者和小团队每天做的是同一件事：看流量、转化、销售、广告有没有异常。Routines 把“记得每天去看报表”变成“有变化再把结论推给我”。

**可用角度：**
- 每天早上打开同一张报表这件事可以删掉了：让 AI 到点自己分析，再把变化发给你
- AI 自动化最实用的场景之一：不是帮你做一次分析，而是每天固定时间重复做同一种分析

## 6. 给 Claude Code / Codex 截图提需求又少一步：按住键边说边圈，它直接生成可粘贴 Prompt

- 链接：https://www.producthunt.com/products/assist-4
- 分类：AI Coding / Mac / 截图工作流
- 发布时间：2026-09-07
- 雷达分：96

Assist 是一个原生 macOS 工具：截图后可一边在画面上圈、模糊、标注，一边说需求，本地模型把语音转写并整理成优化 Prompt，随后直接粘贴给 Codex、Claude Code 等。它还把截图与剪贴板放进 Mac 刘海区域；官方称无服务器、数据本地保存，一次性付费。

**为什么值得发：** 做前端、UI 或根据截图改 bug 时，最浪费时间的往往是“截图 → 圈位置 → 再打一大段解释”。这个工具把三步压成一次按键和一段口述。

**可用角度：**
- 给 Coding Agent 发截图别再打半天字了：圈一下哪里有问题，嘴里说需求，它直接给你整理成 Prompt
- 一个很具体的 AI Coding 小工具：截图、语音标注、Prompt 三步合一，而且转写在本地

## 7. 开会前 30 秒不用再翻 Slack 和邮箱：Remind 会直接把“我要见谁、上次聊了什么”铺满屏幕

- 链接：https://www.producthunt.com/products/remind-7
- 分类：AI 办公 / 会议 / Mac
- 发布时间：2026-09-07
- 雷达分：95

Remind 会在会议开始时弹出全屏提醒、入会按钮和 AI meeting brief。连接 Google 或 Microsoft Calendar 后，可选再接邮件、Slack、Notion，把参会者和相关上下文整理成一页。支持 Zoom、Google Meet、Teams、Webex；macOS 14+，年费 $19.99，提供 7 天试用。

**为什么值得发：** 它解决的不是“AI 帮你总结会后记录”，而是会前那几十秒：你刚从别的任务切过来，却忘了这人是谁、上次说到哪。提醒和上下文一次出现，比再开三个 App 翻记录更直接。

**可用角度：**
- 开会前最狼狈的 30 秒有人做掉了：AI 直接告诉你这人是谁、上次聊了什么，再给一个入会按钮
- 不是会后总结，这个 AI 专门负责让你别迟到、别忘记上一轮谈到哪
