## Huashu Design：让 Agent 先给你看三个设计方向，再做 PPT 和网页

- 项目：https://github.com/alchaincyf/huashu-design
- 推荐指数：91/100
- 新鲜度：网页检索返回 GitHub Trending Today 快照，页面标注今日抓取：该项目显示 +251 stars today。此处记录10月27日趋势观察，不把上榜时间写成项目首发时间；榜单和数字会变化。

中文设计 Skill，可生成网页、App 原型、信息图和 HTML 幻灯片，并可导出可编辑 PPTX；作者提供84种带样张的风格。

先用同一个培训主题比较三个视觉方向，选中后再继续做全套，可以减少整套做完才发现风格不对的返工。

**如何开始**

1. 安装 Node.js 后运行 npx skills add alchaincyf/huashu-design。
2. 在支持 Skill 的 Agent 中输入：做一份 WorkBuddy 入门培训 PPT，先给三个视觉方向。
3. 安装后检查 references、assets、scripts、demos 是否齐全，再挑选方向；导出后在 PowerPoint 逐页检查可编辑性。

**费用与限制**：MIT，个人和商用可免费使用；Skill 本身不等于免费模型，Agent 或 API 费用另算。作者称核心设计和导出可本地运行，可选云功能需自备 Key。PPTX 可编辑文本框不代表复杂元素都能完整还原；README 同时列出不支持图层级可编辑 PPTX 到 Figma 等限制。

## ThinkRail：把 Agent 对话、代码修改和工作区放在同一个界面

- 推荐指数：85/100
- 新鲜度：网页检索返回 GitHub Trending Today 快照，页面标注今日抓取：该项目显示 +1,173 stars today。此处记录10月27日趋势观察，不把上榜时间写成项目首发时间；榜单和数字会变化。

JetBrains 孵化项目，以 pi 编程 Agent 为核心，集成文件、终端、改动对比和基于 Git worktree 的独立工作区，内置简体中文界面。

**如何开始**

3. 从小改动开始，在界面查看对话和 diff；确认结果再自行决定是否合并。

**费用与限制**：Apache-2.0，客户端开源；需要 JetBrains AI 或其他模型供应商，模型费用及免费额度以相应服务为准。Windows x64 可用；这是孵化项目，使用情况统计及错误报告的范围和开关见 README。

**费用与限制**：Apache-2.0，静态扫描可免费使用；可选模型分析需自行配置服务，可能产生模型费用。扫描可能误报或漏报，不能把通过报告当作安全保证；项目会安装第三方依赖。
