## 3. Mycel 拿下 Product Hunt 日榜第一：把服务型一人公司的客户、交付、审批和发票交给 Agent 跑

入口：https://www.producthunt.com/products/mycel

Mycel 9 月 20 日 Product Hunt 日榜第 1。它面向咨询、设计、代理服务等“卖交付物”的业务：拿一份过去交付样例作为基准，后续任务在一次性沙盒中执行，客户、交付、审批、发票和定时任务集中管理，默认所有对外动作经过人工审批。云版从 $299/月起；官方称核心 kernel 可免费自托管，并在条款中注明 kernel 为 Apache-2.0。官方也明确当前无 SOC2、无特殊类别数据分级，不适合医疗/生物等敏感数据。

## 6. Jev 火了之后，GitHub 今天第一名冒出本地替代 Laya：不用生成文字，直接做 choice / score / yes-no 决策

入口：https://github.com/NandhaKishorM/laya

Laya 在 9 月 21 日 GitHub 趋势监测中约 +2,194 stars/day，同时位列 Hugging Face Trending 前列。它用 ModernBERT/mmBERT 做非自回归 typed decisions：对文本、邮件、工单或 JSON 一次前向直接输出 choice、score、yes/no 概率，不做文本生成；仓库提供 PyPI、Colab 和 Hugging Face 权重，README 标注 Apache-2.0。作者报告 T4 单问题约 33ms、批量约 7.2ms/题，这些是项目自测，不应当作通用性能保证。

**为什么值得发：** Jev 最大门槛之一是 early access/API；Laya 给了一个可本地部署、可看权重、可自己验证的同类思路，适合路由、分类、审批条件和 Agent 快速决策。

**选题角度：** Jev 还在排队？GitHub 今天爆了个本地开源替代 Laya / Agent 不是什么都需要大模型长篇思考：有些决策 30ms 直接给概率

## 7. Browser Use 把 Jev 塞进浏览器 Agent：Google Flights 演示 7 秒完成，默认循环甚至不需要截图

入口：https://github.com/browser-use/jev-ultrafast

browser-use/jev-ultrafast 9 月 21 日继续高速 Trending，监测约 +2,174 stars/day。它把页面变成编号控件表，让 Jev 一次请求选 operation + target，仅在 TYPE_TEXT 时调用一个小型文本模型。项目展示 Google Flights Zürich→London 7.073s 的实测录像；6 次配对实验中优化版与基线各 3/3 通过，作者明确说明这只是单任务小样本，不代表通用可靠性。运行仍需要 TypeSafe API Key 和文本模型 API Key，Shadow DOM、iframe、canvas、上传等能力尚有限。

**为什么值得发：** 这是 Jev 从“概念模型”落到真实网页操作的最好演示之一，能直接看到结构化决策为何可能比每一步截屏+大模型推理更快。

**选题角度：** 浏览器 Agent 终于不磨叽了：查一趟 Google Flights 只用了 7 秒 / 它快的关键不是更强大模型，而是根本不让大模型每一步看截图

## 8. Vercel json-render 再次爆发：让 AI 只生成 JSON，不准乱写 UI 代码

入口：https://github.com/vercel-labs/json-render

Vercel Labs 的 json-render 在 9 月 21 日重新进入 GitHub Trending，监测约 +381 stars/day；最新 v0.21.0 为 9 月 18 日。开发者先定义可用组件和动作 catalog，模型只能返回符合 schema 的 JSON，再由受控 renderer 渲染，避免模型随意生成不受控 JSX/HTML。Apache-2.0，现支持 React、Vue、Svelte、Solid、React Native、Next.js、PDF、邮件、Remotion 视频、3D 和终端界面，内置 36 个 shadcn 组件。

**为什么值得发：** 做 Vibe Coding 或动态 AI 界面时，可以同时保留生成式 UI 的灵活性和设计系统/权限的硬约束，特别适合避免页面越改越乱。

**选题角度：** Vercel 的办法很直接：AI 可以设计页面，但不准自己写组件 / 同一份 AI JSON 能渲染网页、App、PDF、邮件甚至 3D

## 9. Builder.io Agent-Native 今日 Trending：Agent 干活和人类 UI 共用同一套 Action，不再靠 AI 点自己的网页

入口：https://github.com/BuilderIO/agent-native

BuilderIO/agent-native 9 月 21 日列入 GitHub Explore Trending。它把每项业务能力定义一次为 action：Agent 作为 tool 调用，人类 UI 从代码里调用同一实现，校验、权限、数据和状态共享；同一个 action 还能暴露为 HTTP、MCP、A2A 和 CLI。框架包含 auth、permissions、skills、memory、automations、agent teams 和 PostgreSQL/PGlite。README 称其为 open-source，但 GitHub 当前未识别明确 License，商业采用前应自行确认许可。

**为什么值得发：** 真正做 Agent 产品时，比“让 Agent 操作自己网站按钮”更干净：人和 Agent 走相同业务接口，UI 只负责让用户检查、修改和批准。

**选题角度：** Agent 产品不应该让 AI 在自己网页上点按钮：Builder.io 给了另一种架构 / 一个 Action 同时给 UI、Agent、MCP、API 用，Agent App 的代码终于不用写两套

## 11. Cua 今日 Trending：给 Agent 一台真正可操控的电脑，本地 Mac VM 和云桌面都能跑

入口：https://github.com/trycua/cua
