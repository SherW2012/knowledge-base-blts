## 1. Claude Projects 重做：给一个项目目标，协调 Agent 自动分工、并行运行、共享记忆

官方：https://claude.com/blog/projects-redesigned

Anthropic 9 月 17 日宣布重新设计 Claude Code Projects：不必手动把开发目标分给多个会话，由协调 Agent 规划、发任务、审结果、汇总交付。每条线程是独立的云端 Claude Code 会话，使用自己的仓库副本和分支，各线程共享项目记忆；可从手机查看和引导进度。**当前 beta 仅先开放部分无既有 Web/桌面 Projects 的 Claude Pro/Max 云端 Claude Code 用户**，后续扩大；并行全额消耗用量更快，多个线程改同一文件仍有 Git merge conflict 风险。

**为什么值得发：** 同一个 MVP 里网页、API、测试不必反复给不同 Agent 贴背景。可以把项目目标作为入口，同时关注账户开放状态、额度和最终代码合并。角度：**Claude Projects 从文件夹变成 Agent 项目经理：你定目标，它拆任务开分支。**

## 2. OpenAI 发布 Astra for Law：GPT-6 Astra + 法律索引 + 26 个专业插件

官方：https://openai.com/index/astra-for-law/

OpenAI 9 月 17 日推出法律方向的 Astra for Law，基于 GPT-6 Astra 配置美国判例、法规等法律索引、专业写作与分析指令以及 26 个法律生态插件；还公布 9 个社区插件、47 个可复用法律 Skills，并宣布 ChatGPT for Word GA。**法律专用模型目前仅给选定律所通过 Trusted Access 使用，API 仍在后续计划**；并非所有人 ChatGPT 已能切换，仍须人工审核法律引用和保密材料。

**为什么值得发：** 专业 Agent 产品不只是替模型写一句系统 Prompt，重要的是可信专业数据、行业软件入口和权限控制。这次有明确实际工具及开放边界。角度：**OpenAI 正式做法律专版：检索 2.3 亿 URL 语料，配 26 个行业插件，但普通人暂时拿不到模型。**

## 3. CREEM 2.0：AI 小产品做完以后，订阅、点数计费、税务与分销一处搞定

产品：https://www.creem.io/

9 月 17 日 Product Hunt 榜首。Creem 2.0 是 Merchant of Record，处理付款、税务、发票和争议；有一次性付款、订阅、预付 credits、token/API 用量计费、联盟营销分成，以及 API、SDK、CLI，便于 Coding Agent 集成。官方标准收费为 **成功交易 3.9% + $0.40/笔**，**无月费、无设置费不等于交易免费**；个人所在地能否通过注册/KYC/提现需实际核对。

价格：https://www.creem.io/pricing

**为什么值得发：** Vibe Coding 最后一步往往卡在收款、税务、按次扣费。可以直接评估已有支付后端，但低客单价先算每单固定手续费。角度：**网站做好了怎么收钱？CREEM 2.0 连 AI 点数计费都给你备好了。**

## 4. Zella：免费、无水印，本地一键把录屏剪成带字幕和配音优化的短视频

官网：https://zellahq.com/

9 月 17 日 Product Hunt 上榜，支持 Mac 和 iPhone。录制视频后 Auto-Polish 自动删停顿/口头禅、生成字幕、清理声音、剪节奏和放大重点；iPhone 可转 9:16，处理主要在本地，离线运行，首次需下载字幕模型。**免费完整功能但每次导出最长 2 分钟、最高 1080p；去限制 $89 一次性买断 Mac+iPhone**。可选外部 AI Assistant 需用户自带 API Key，并非所有功能永不连网。

**为什么值得发：** 科技博主拍功能演示，录一遍后不想再逐帧剪掉卡壳、打字幕；两分钟免费输出已足够许多短帖。角度：**录完屏 AI 自动帮你删停顿、加字幕：这个 Mac/iPhone 剪辑器免费无水印。**

## 5. 腾讯云 Octop 今日进 Trending：自托管的多用户 AI 助手，可接 QQ、飞书和定时任务

仓库：https://github.com/TencentCloud/Octop

9 月 18 日当日 Trending 有日期快照显示 Octop 突增热度，约 +386 stars today；仓库 MIT。Octop 把 Web 控制台、CLI、多人隔离、不同专家 Agent、RAG 知识库、长期记忆、定时任务和 QQ、飞书、钉钉、Discord、企微连接放进自托管平台；ACP 可以调用 Claude Code / Codex。官网仓库提供 Windows、Mac、Linux 桌面安装包与命令行方式。**开源程序不意味着第三方模型和机器资源免费，开放远程访问时注意账户/工具权限**。

**为什么值得发：** 想做个人或团队 AI 助理，不用从零拼用户管理、消息入口和计划任务，也可以先本地部署。角度：**腾讯云放出 Octop：一个后台给家人或团队各配一个 AI 助手。**

## 6. Bitrise Remote Dev Environments：一台 Coding Agent 分一台云 Mac，和 CI 用同一套环境

官网：https://bitrise.io/platform/remote-dev-environments

9 月 17 日 Product Hunt 新上线。RDE 提供 Apple Silicon Mac/Linux 虚拟机，带 Xcode、Git、Docker、npm 和 CI 同款工具缓存，可经 MCP 并行分配给 Claude Code/Codex，VS Code、Cursor 远程接入，用完归档保存环境。**官方文档显示产品 9 月 10 日就已 GA，这次新鲜度是 9/17 PH 上线而非首次 GA**。Basic 月付 $20 或年付折合 $18/月，含 1,440 分钟/OS，额外机器分钟和模型另计。官网服务目前标注美国/欧洲区域。

产品时间：https://docs.bitrise.io/en/bitrise-ci/changelog

**为什么值得发：** 多 Agent 在一台电脑抢目录和 CPU 不是唯一选择：可以给不同任务隔离完整机器，尤其适合 iOS 项目真实构建和复现 CI 问题。角度：**以后不只一 Agent 一 Worktree，而是一 Agent 一台云 Mac。**

## 8. Text Agent Store：不用下载 App，把 AI Agent 存成手机号直接发短信

产品：https://www.imessage.store/

9 月 17 日 Product Hunt 新上架。开发者声称目录目前收录约 137 个短信/iMessage Agent，覆盖旅行、日程、招聘等。按类目找到联系人，直接发消息启动，不用另装 App 或开目录账号；这更像**Agent 的分发目录**而不是平台独立开发并验证的 137 个免费模型。第三方服务费、SMS 运营商费、美国号码和支持区域可能有限制，不应上传个人隐私。
