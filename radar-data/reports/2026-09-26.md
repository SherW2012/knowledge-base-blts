## 4. Hindsight 今日 +1,600 Star：Agent Memory 不只“记住”，还会从长期经历里形成 mental model

入口：https://github.com/vectorize-io/hindsight

vectorize-io/Hindsight 本轮趋势监测约 +1,653 stars today，MIT。它把 Agent memory 拆成 retain / recall / reflect，并进一步维护 mental models 与 knowledge pages，目标是让 Agent 从长期交互中更新理解而不只是检索聊天记录。可 Docker、pip、Kubernetes 或嵌入式运行，支持 25+ 模型提供商及 Ollama/LM Studio/llama.cpp 等本地模型；也提供 MCP、Python/Node/Go 客户端和两行代码的 LLM wrapper。托管 Cloud 按使用量计费，有起始免费 credits。

**选题角度：** Agent Memory 开始从“聊天记录搜索”进化成“会形成看法”了 / 两行代码给现有 Agent 加长期记忆：Hindsight 今天爆了
