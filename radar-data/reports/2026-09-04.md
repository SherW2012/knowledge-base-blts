## 最终精选 8 条

### 1. GPT-6 Astra 正式发布：重点是直接替你操作电脑干完整任务

OpenAI 9 月 3 日正式发布 GPT-6 Astra。官方定位为新一代端到端工作模型，强化 computer use、浏览、编程、科研和专业工作；在 ChatGPT 中能按模板制作文档、表格和演示，并在用户追加要求后继续调整。当前先向有限组织开放，Plus、Pro、Business、Enterprise 与 API 将在随后几天逐步扩大。

**为什么值得发：** 昨天还是“GPT-6 热搜”，今天已经正式官宣。普通用户真正能感受到的不是 benchmark，而是让模型连续打开网页、操作软件、做文档、跑多步任务。

**推荐角度：** GPT-6 真的来了：OpenAI 这次想让模型从“回答你”变成“替你操作电脑”。

官方：https://openai.com/index/safety-overview-gpt-6-astra/

### 2. Omi 把“电脑记忆”做出来了：问“我昨天在干嘛”，它能从屏幕和会议里找答案

Omi 新版 Mac 应用会在用户允许的范围内记录屏幕与会议，包括 Zoom、Meet、Slack huddle 和线下对话。之后可在任意 App 里问“上次会议聊了什么”“昨天我在做什么”“帮我写跟进”，答案会标出来自哪段屏幕或会议。项目强调 local-first、开源，也允许暂停和删除记录。

**为什么值得发：** “AI 记得我电脑上看过和听过什么”是一秒能理解的第二大脑场景：找信息、回忆会议、补跟进，不需要自己维护一套笔记。

**推荐角度：** 问电脑一句“我昨天干嘛了”，它真的能从你看过的屏幕里翻出来。

产品：https://www.producthunt.com/products/open-source-ai-necklace-friend?launch=omi-3

### 3. Airtop Agent Builder：网页自动化坏了以后，Agent 还能自己修

用户用自然语言描述网页工作流后，Airtop 把它编译成可重复运行的自动化。网站改版导致任务失败时，它会定位问题、生成修复草稿并实际测试；修好后仍由用户决定是否部署。可处理登录后的网页、表单和数据提取。

**为什么值得发：** 网页自动化真正麻烦的是维护，而不是第一次搭建。网站一改版脚本就废，这个更新直接打掉最烦的一层人工维护。

**推荐角度：** 以前网页自动化最怕网站改版，现在 Agent 连自己坏了都能先修一遍。

官方：https://www.airtop.ai/agent-builder

### 4. Google 把“直接说话办事”塞进 Gmail / Docs / Keep

Google 9 月 3 日正式上线 Gmail Live、Docs Live、Keep Live。可以直接问 Gmail“我的航班登机口在哪”，在 Docs 里边说边组织成文档，或者把 Keep 里的口述脑暴自动整理成列表和笔记。本周开始向部分 Google AI Plus / Pro / Ultra 用户推出，企业 Workspace 后续跟进。

**为什么值得发：** 不是多一个聊天框，而是把找邮件、起草文档、记想法这些高频动作直接变成对话，手机或走路时尤其有感。

**推荐角度：** Google 开始把键盘拿走：Gmail、Docs、Keep 现在直接跟你对话。

官方：https://blog.google/products-and-platforms/products/workspace/voice-features-gmail-docs-keep/

### 5. Tidy：Mac 上免费的“去 AI 味”快捷键

在任何 Mac App 里选中文字后按快捷键，Tidy 会原地修拼写和语法；另一个快捷键专门把明显的 AI 腔改回更自然的表达。它调用 macOS 自带的 Apple Intelligence 本地模型，文字不上传；需要 macOS 26 且开启 Apple Intelligence。

**为什么值得发：** Slack、邮件、文档里反复复制到 ChatGPT 再粘回来很烦。这个工具把润色和去 AI 味缩成一次快捷键，而且免费、本地。

**推荐角度：** 不用再复制到 ChatGPT：任何 Mac App 里直接原地改语法、去 AI 味。

产品：https://www.producthunt.com/products/tidy-6

### 6. Readr：免费的“会聊天的电子书阅读器”，而且不会剧透

Readr 是免费开源的 iPhone、iPad、Mac 阅读器，可打开 EPUB、PDF、Markdown。选中段落就能提问，答案直接出现在页边并引用整本书里的相关位置；还能只基于你已经读到的部分做无剧透回顾，并用设备端语音朗读。

**为什么值得发：** 看长 PDF 或电子书不用再在阅读器和 ChatGPT 之间来回复制粘贴，提问、回顾、朗读都留在阅读现场。

**推荐角度：** 读小说忘了前面人物关系？它只总结你已经看过的部分，不剧透。

产品：https://www.producthunt.com/products/readr-3

### 7. Blume.codes：把你反复纠正 Claude / Codex 的内容自动沉淀成 Rules / Skills

Blume 是放在 Claude Code、Codex、Cursor 旁边的桌面 App，在本地观察 coding agent 会话。反复出现的人工纠正会被归纳成规则，稳定工作流会被沉淀成 Skill，让后续 Agent 少重复犯同类错误；代码和聊天内容不需要上传到它的服务器。

**为什么值得发：** 很多人已经会写 CLAUDE.md、rules、Skills，但最大问题是懒得持续维护。Blume 把“这次教训”变成下次能复用的规则。

**推荐角度：** AI Coding 最烦的不是第一次犯错，是你骂了十遍它还会犯：这个工具专门记住你的纠正。

产品：https://www.producthunt.com/products/blume-codes

### 8. Tabbit AI：浏览器从“问网页”变成“把任务交给它”

Tabbit 能把网页、PDF、截图、本地文件、书签等直接作为 Agent 上下文，让不同 Agent 做研究、抓取、写作和数据分析；付费档支持定时任务，也能把任务结果输出成文档等交付物。官方提供免费档体验基础 AI 浏览与任务能力。

**为什么值得发：** 普通浏览器 AI 多半停在总结当前页；Tabbit 更像把整组网页和文件变成 Agent 工作区，让它自己完成一段流程。

**推荐角度：** AI 浏览器下一步不是总结网页，而是你把任务扔进去以后自己跑。

产品：https://www.tabbit.ai/
