## 最终精选 8 条

### 1. Claude Fable 5.1：Agent 重度用法最高能省约 45% 成本

Anthropic 发布 Fable 5.1。真正值得普通用户和开发者关注的不是 benchmark，而是缓存读取价格降到上一代的四分之一；Anthropic 估算典型工作负载约省 25%，高度 Agent 化任务最高约省 45%，同时误拦截减少。

**为什么值得发：** 新模型发布里少见的直接用户体感——更便宜、少误伤，而且已经可用。

**推荐角度：** Claude 新模型最值得看的不是分数，是 Agent 账单终于往下掉了。

原始源：https://www.anthropic.com/claude/fable

### 2. slotstream：104GB Qwen3.8，48GB Mac 也能跑

slotstream 从 SSD 流式加载 MoE experts，让装不进内存的 Qwen3.8-Flash-Next 也能在 Mac 上跑。README 给出的 48GB M5 Pro 数据约为 12 tok/s warm decode、约 32GB 峰值进程内存，并兼容 Ollama / OpenAI Chat API。

**为什么值得发：** 这是非常直观的门槛变化——以前看到 104GB 权重直接放弃，现在高配 Mac 也有机会跑。

**推荐角度：** 104GB 模型塞不进 48GB 内存？那就从 SSD 边读边跑。

项目：https://github.com/carloslfu/slotstream

### 3. Murmell：AI Agent 的 Google Docs，合上电脑还能继续跑

Murmell 今天重新上线，把 Claude Code、Codex、Kimi、OpenCode 等放进同一个云端 canvas：同一仓库、实时终端、共享预览。电脑合上后 Agent 继续干活；统一 memory 还能让不同 Agent 接着同一份上下文工作。

**为什么值得发：** “多个 Agent 在同一个 Google Docs 式房间里工作”比讲 orchestration 好懂一百倍，而且直接解决长任务和切 Agent 重复解释的问题。

**推荐角度：** Claude 写一半换 Codex，居然能接着同一份上下文继续干。

产品：https://www.producthunt.com/products/murmell

### 4. Kilo Code for JetBrains：把 IDE 变成多 Agent 控制室

Kilo Code 的 JetBrains 原生插件支持多个 coding agents 并行工作，每个 Agent 用独立 git worktree，可以直接跑现有 Run Configurations、看 diff 和 GitHub PR，并支持 600+ 模型。Kilo 主仓库约 2.7 万 Star，本窗口末端仍有更新。

**为什么值得发：** Java / Kotlin / Android / JetBrains 用户终于拿到的不只是 AI 聊天侧栏，而是一套原生多 Agent 工作流。

**推荐角度：** IntelliJ 用户终于不用看着 Cursor 吃独食了。

官方：https://blog.kilo.ai/p/kilo-for-jetbrains-a-multi-agent-control-room

### 5. mcptunnels：MCP 也有自己的 ngrok 了

一条命令把本地 stdio MCP server 暴露成公网 URL，不用账号，不用先配云服务；默认带 OAuth 2.1 密码保护，ChatGPT、Claude、Cursor 等可走标准认证流程。

**为什么值得发：** 给云端 Agent 临时连接本地 MCP，一直是非常具体的最后一公里问题，这个工具把它压成了一条命令。

**推荐角度：** 本地 MCP 想让 ChatGPT / Claude 远程连？一条命令上公网。

项目：https://terragohan.github.io/mcptunnels/

### 6. Qwen3.8-Flash-Next：GGUF 本地推理多了一个 MTP 加速玩法

Unsloth 给 Qwen3.8-Flash-Next-GGUF 补上 MTP 使用说明和 sidecar，可在对应 llama.cpp 分支/预编译版本里通过 `--spec-type draft-mtp` 开启。LocalLLaMA 当天讨论超过 400 赞；社区有人反馈明显提速，也有人效果一般，因此不把最好成绩当普遍 benchmark。

**为什么值得发：** 不是讲 MTP 原理，而是已经在本地跑 Qwen3.8 的人今天就能复制命令尝试。

**推荐角度：** 不换显卡、不换量化，同一个模型再试一个免费的 tok/s 加速开关。

说明：https://huggingface.co/unsloth/Qwen3.8-Flash-Next-GGUF/blob/main/MTP/README.md

### 7. Computable GPU Index：GPU 租价也有公开指数 + MCP 了

CGI 把多家云厂商的按需 GPU 租赁价格整理成公开、可复现的 USD/GPU-hour 指数，目前覆盖 H100、H200、B200、B300。代码、记录、复现命令公开，还提供 API / MCP 给 Agent 查询。

**为什么值得发：** 做 AI 项目估算算力成本，不必再开十几个云厂商页面手抄价格；Agent 也能把 GPU 市场租价当实时数据源。

**推荐角度：** 如果你经常租 GPU，这个开源价格指数值得直接收藏。

项目：https://github.com/getcomputable/gpu-index

### 8. Weedout：专门帮你屏蔽 YouTube 的 AI 垃圾视频

Weedout 是 macOS Safari 扩展，只根据 YouTube 自己的 “Made with AI” 标签过滤视频：首页、搜索、相关推荐、播放列表和 Shorts 都能隐藏。本地运行、无账号、无追踪，一次性 $1.99。

**为什么值得发：** 很反常识，但比很多高深 AI 新闻更贴近日常：AI 工具越多，“帮我少看一点 AI 垃圾”本身也开始成为产品需求。

**推荐角度：** 最讽刺的 AI 热点：现在连“屏蔽 AI 视频”都成一门产品了。

项目：https://masteranza.github.io/weedout/
