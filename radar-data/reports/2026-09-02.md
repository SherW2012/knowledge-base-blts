## 最终精选 8 条

### 1. Claude Fable 5.1：Agent 重度用法最高能省约 45% 成本

真正值得关注的不是 benchmark，而是长任务 / Agent 工作的成本下降和误拦截减少。

原始源：https://www.anthropic.com/claude/fable

### 2. 李飞飞发布 Atlas：几张照片就能重建 3D，还能重新选机位拍“子弹时间”

World Labs 发布新一代 Atlas。官方展示中，1–6 张参考图可按精确相机轨迹生成最长 1 分钟、1440p 视频；还能从少量照片重建 3D 场景，把普通多机位素材重新构图成类似“子弹时间”的视角。目前只对部分合作伙伴开放 early access。

**为什么值得发：** 不需要先解释世界模型。用户一眼就能理解“拍完以后还能重新选机位”有什么用，视觉 Demo 也非常强。

原始源：https://www.worldlabs.ai/blog/atlas

### 3. Murmell：AI Agent 的 Google Docs，合上电脑还能继续跑

把 Claude Code、Codex、Kimi、OpenCode 等放进同一个云端工程：同一仓库、共享终端和预览；电脑合上后任务继续跑，不同 Agent 还能继承同一份上下文。

产品：https://www.producthunt.com/products/murmell

### 4. Kilo Code for JetBrains：把 IDE 变成多 Agent 控制室

多个 coding agents 在 JetBrains 里并行工作，每个 Agent 独立 worktree，可直接跑现有 Run Configurations、看 diff 和 PR。

官方：https://blog.kilo.ai/p/kilo-for-jetbrains-a-multi-agent-control-room

### 5. “GPT-6”冲上 X 热搜：但 OpenAI 官方确认的其实是 Astra 正在准备发布

X 上 `GPT-6` 讨论升温，但截至本轮扫描，OpenAI 没有正式宣布“GPT-6”这个产品名。9 月 1 日官方真正确认的是：正在准备发布 Astra；Astra 已成为 OpenAI 首个达到 Preparedness Framework 网络安全 Critical 阈值的模型，并显著强于 GPT-5.6 Sol 的网络安全能力。

**为什么值得发：** 热度很高，而且可以直接给用户一个“别被标题骗”的信息差：可以谈 GPT-6 热搜，但不能写成 GPT-6 已官宣 / 已发布。

原始源：https://openai.com/index/path-to-astra/

### 6. Qwen3.8 本地推理多了个免费加速玩法：MTP 可以直接开

已经在本地跑 Qwen3.8 的用户，不换显卡、不换量化，可以通过新的 MTP 参数尝试提速。社区反馈有差异，因此不包装成普遍 benchmark。

说明：https://huggingface.co/unsloth/Qwen3.8-Flash-Next-GGUF/blob/main/MTP/README.md

### 7. GPU 租价终于有公开指数了：H100 / H200 / B200 / B300 一眼比价

Computable GPU Index 把多家云厂商的按需 GPU 租赁价格做成公开、可复现的 USD/GPU-hour 指数，还提供 API / MCP 给 Agent 查询。

项目：https://github.com/getcomputable/gpu-index

### 8. Weedout：专门帮你屏蔽 YouTube 的 AI 垃圾视频

Safari 扩展只根据 YouTube 自己的 `Made with AI` 标签过滤视频，可隐藏首页、搜索、相关推荐、播放列表和 Shorts；本地运行、无账号、无追踪。

项目：https://masteranza.github.io/weedout/
