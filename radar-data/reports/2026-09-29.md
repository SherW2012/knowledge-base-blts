## 1. Claude Sonnet 5.5 正式发布：输出快 30%+，多数任务总成本最高降约 30%，但 token 单价没涨

入口：https://www.anthropic.com/claude-sonnet-5-5

Anthropic 9 月 28 日发布 Claude Sonnet 5.5。官方称其相对 Sonnet 5 输出速度提升 30% 以上，并因更少 token 使用让多数任务总成本最高降低约 30%；API token 单价仍为输入 $2/百万、输出 $10/百万。它定位为 Opus 5.5 的更快低成本补充，重点覆盖日常 coding、bug 修复，以及文档、幻灯片和表格等工作；已在 Claude 平台及 AWS、Google Cloud、Azure 等渠道提供。

**为什么值得发：** 对日常 Coding Agent 和内容工作，真正变化不是“再多一个模型名”，而是更低任务总成本和更快反馈，且无需接受更高 token 单价。

**选题角度：** Sonnet 5.5 不是单纯变强：同价、更快、任务总成本反而更低 / 日常 coding 不一定再需要一直上 Opus：Anthropic 给 Sonnet 重新定了位

## 3. NVIDIA 发布 Open Agent Safety：Agent 越权不只靠 Prompt 拦，开始下沉到内核和 BlueField 硬件

入口：https://developer.nvidia.com/blog/nvidia-open-agent-safety-platform-a-reference-for-continuous-in-silicon-agent-monitoring/

NVIDIA 9 月 28 日发布 Open Agent Safety Platform，由开源 OpenShell 安全运行时和 Sentry 参考系统组成。OpenShell 在沙箱内通过内核级控制约束文件、系统调用、网络和凭据，策略变更还可先做形式验证；Sentry 则把独立监控下沉到 BlueField-4 DPU，可在 Agent 越界时进行隔离。OpenShell 为 Apache-2.0，也可扩展到第三方计算平台，并提供 Agent Skills、Python/TS/Go/Rust SDK。

**为什么值得发：** Agent 能读文件、装包、调 API 以后，安全边界不能只靠 system prompt。OpenShell 给开发者一条今天就能试的“Agent 沙箱 + 权限策略”路线。

**选题角度：** NVIDIA 的新思路：不相信 Agent 自己守规矩，直接在内核和硬件旁边盯着它 / OpenShell 开源：给 Claude/Codex 这类 Agent 套一个真正能限制文件、网络和凭据的笼子

## 4. H Company 开源 Holo4：同一个 27B Agent 模型能点 GUI、写代码、调 MCP/API，还开放全部 benchmark 轨迹

H Company 9 月 28 日发布 Holo4 系列：27B dense、35B-A3B MoE，以及 Holotron4 Nano。Holo4 不绑定单一接口，可在桌面、网页、Android、代码沙箱及业务 API 环境里同时使用 GUI、代码、MCP 和 API。官方开放 BF16/FP8/NVFP4/4-bit GGUF 权重，并公开 benchmark 轨迹与数据；API 也同步可用。官方自测中 Holo4-27B 在 OSWorld 2.0 得 61.7%，但不同模型的 harness、任务子集和评测设置并不完全一致。

**选题角度：** 真正的 open computer-use 模型来了：GUI、代码、MCP、API 一个模型全包 / Holo4 最值得看的不是分数，是它连完整操作轨迹也一起开了

## 7. VibeDefend：安全规则直接塞进 Claude Code / Codex，危险命令和读密钥在执行前就拦

## 8. AutoHarness 今日爆发：Claude Code 不用你手写 Skill，它会从真实工作会话里自己提炼、合并、更新和淘汰

入口：https://github.com/tigerless-labs/autoharness

tigerless-labs/autoharness 本轮 GitHub/Trendshift 出现明显当日增长。它是 MIT 的 Claude Code 插件，监听真实 coding sessions，在工作量达到阈值后后台反思，把可复用经验写成 `.claude/skills/`；遇到同场景不会无脑堆新 Skill，而会合并/更新，并基于后续真实使用率把长期没用的自生成 Skill 归档。它只管理自己写的 Skill，不碰人工或第三方 Skill；无 daemon，Python 3.11+，可通过 Claude plugin marketplace 安装。

**为什么值得发：** Skill 最大的维护成本正是“什么时候该写、写完会不会过期”。AutoHarness 把这件事变成从真实工作中自动积累，而不是每次靠人总结。

**选题角度：** Claude Code 开始自己养 Skill 了：干过一次，下次自动记成流程 / 最关键的是它会删：不是让 `.claude/skills` 最后堆成垃圾场
