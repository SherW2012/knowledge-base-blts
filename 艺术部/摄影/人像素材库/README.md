# 人像素材库

人像出片的两套分类同时存在，各自解决一个问题。

## 两条线怎么分

| 分类 | 解决的问题 | 有没有地点 | 对应文档 |
| --- | --- | --- | --- |
| 按地点 | 我要去哪儿拍，到了拍什么 | 有真实经纬度，落在地图上 | [杭州拍摄地图](01-杭州拍摄地图.md) |
| 按风格 | 我刷到一张好看的客片，想存下来当参考 | 没有地点，只认风格 | [风格灵感库](02-风格灵感库.md) |

按地点这条线是**执行用的**：出门前挑地点，看这个地方别人拍出过什么、什么季节什么时段去、机位在哪。地点带类型（自然景观、咖啡店、城市街区、建筑空间、工业遗址……），地图上按类型区分颜色。

按风格这条线是**养眼睛用的**：在小红书刷到不知道在哪拍的好看客片，先按风格丢进去。哪天认出地点了，再把它挪到地点那条线下面。

目前地点聚焦杭州。以后要加别的城市，改一下文档里的 `范围`，再往下加地点就行。

## 界面

两份文档都是一本可以翻的相册：每页四张，翻页有立体翻纸动画，右侧页边是书签，按类型或风格分栏，点书签直接跳到那一章。点照片看大图，左右方向键翻。

地点那份在相册上方多一张杭州地图，标记按类型着色并编号，编号和相册里的地点序号一一对应。点地图上的标记，相册翻到那个地点；反过来在地点扉页点「在地图上定位」，地图放大到那个点。

## 素材放在哪

照片不进 Git 仓库。传到 R2 之后，把外链填进文档里对应的那一行。没填链接的位置会显示成「待补充」的空框，所以可以先把想拍的画面列成清单，拍完再回来补链接。

## 写法

素材写在文档的 `portrait-gallery` 代码块里，纯文本，一行一条。

```text
标题: 杭州人像地图
模式: 地点                          # 地点 或 风格
城市: 杭州
范围: 30.10, 119.98, 30.45, 120.42   # 南, 西, 北, 东 四条边的经纬度
说明: 一句话介绍

@地点 良渚古城遗址公园
类型: 自然景观
风格: 森系, 治愈
坐标: 30.3925, 120.0293
时段: 10—11 月芦苇白，16:30 后侧逆光
机位: 南入口进去右手边芦苇荡
笔记: 园区大，电瓶车必坐
- https://图片外链/01.jpg | 芦苇逆光半身 | 85mm f1.8
- 木栈道回头全身                      # 还没拍，先占个位
```

规则就这几条：

- `@地点 名字` 或 `@风格 名字` 开一个新章节，章节之间不用空行也行。
- `键: 值` 是这一章的信息。`类型`、`风格`、`坐标` 有特殊含义（决定颜色、地图落点），其余的键随便写，会原样显示在扉页上，不用改代码。
- `坐标` 写 `纬度, 经度`，不写就不出现在地图上，但相册里照常有这一章。
- `-` 开头是一张素材，用 `|` 分成 `链接 | 说明 | 备注`。第一段不是链接时，整行都当说明，显示成待补充的空框。
- `#` 开头的行是注释。

## 扩展

- **加地点**：在地图文档里加一段 `@地点`，填上坐标就自动出现在地图上。
- **加类型或风格**：直接写新名字。没预设过的名字会按名称散列出一个固定颜色，图例、书签、标记会一起跟上。
- **加城市**：新建一份文档，改 `范围` 为那个城市的经纬度范围。底图目前只画了杭州，其他城市先只有网格和标记。

底图是按真实经纬度画的示意图，不是测绘数据，只用来判断相对位置。标记用的是真实坐标，但都是大致位置，具体机位以现场为准。
