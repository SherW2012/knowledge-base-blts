## 人像素材库

出片素材单独成库，分两条线：[按地点](人像素材库/01-杭州拍摄地图.md)在地图上标注拍摄点并区分类型，[按风格](人像素材库/02-风格灵感库.md)收集不知道地点的客片。两条线的写法和扩展方式见[素材库说明](人像素材库/README.md)。

## 使用方式

技巧、设备、地点、案例尽量拆成独立 Markdown 文档。图片与视频后续优先放到 R2，对应文档里只保留链接和必要说明。
