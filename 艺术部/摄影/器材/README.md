# 器材

每台设备一篇，写的是**使用经验**，不是参数。

参数（三围、传感器、焦段、光圈、重量、标签、用途）统一维护在虚拟器材室的数据文件里，一处改处处生效；这里的文档只回答四个问题：什么时候想拿它、什么场景最好看、什么场景容易翻车、我的参数习惯。样片以后挂在最后一节，走 R2 外链。

## 为什么这样分

参数是死的，抄一遍只会两处不一致；经验是活的，越写越值钱，而且写在 Markdown 里才能被站内搜索搜到、才能像别的文档一样越写越长。虚拟器材室里点开任意一台设备，右侧面板底部的「使用经验 →」就跳到这里对应的那一篇。

## 新增一台设备

1. 在 `site/gear-data.json` 里加一条：`id`、`name`、`brand`、`category`、`form`、`dimensions`（毫米，宽 × 高 × 厚）、`tags`、`usage`。
2. 在这个目录下建一篇同名文档，把文件名填进那条数据的 `note`。
3. 有真实 GLB 模型时，放进 `site/models/`，把路径填进 `modelPath`，场景会自动改用它并缩放到 `dimensions` 给的真实尺寸。

不填 `modelPath` 时，场景按 `form` 和 `dimensions` 参数化生成机身，比例是真实的。
