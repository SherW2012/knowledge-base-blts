# 诗词

自己写的诗、词与散文，分两集存放。

```poetry-shelf
标题: 诗词
说明: 两集分开收：华叶集收诗，绒草集收词与散文。分法按大体走向，不必较真——一首长短句写得像诗，放哪边都行。

@ 华叶集
副题: 诗
色: 青
印: 华
文档: 华叶集.md
简介: 律绝与古体。写志、写景、写一时兴起。

@ 绒草集
副题: 词 · 散文
色: 赭
印: 绒
文档: 绒草集.md
简介: 长短句与散记。写情、写日常、写说不清的东西。
```

也可以直接进：[华叶集](华叶集.md) · [绒草集](绒草集.md)

## 怎么添稿

两集都是一本可以翻的书，正文写在文档的 `poetry` 代码块里。一首一段，`@` 起题，下面直接写正文：

```text
@ 无题
青林翠竹英雄魄，碧水丹心少年魂。
莫道遥观尽飞雪，只因前路未逢春。
```

规则很少：

- `@ 题名` 开一篇。没题就写 `@ 无题`。
- 紧跟在题后面的 `键: 值` 是这一篇的信息，比如 `体裁`、`词牌`、`时间`、`小序`。写不写都行。
- 一旦出现第一行正文，后面就全是正文，不再当信息解析——所以正文里出现冒号不会被误读。
- 正文里空一行表示分段。散文靠这个分自然段。
- 万一某行正文确实要以 `键: 值` 的样子开头，在行首加一个 `|`，这行就强制当正文。
- 集子本身的信息写在最上面：`集名`、`副题`、`色`、`印`、`说明`、`排版`。

## 排版

默认竖排右起，题在最右，一句一列，落款印在最左——和线装书一个读法。工具条上可以切成横排。标了 `体裁: 散文` 的篇目字号会自动放小、行距收紧，长文读起来不累。

书页支持全屏（工具条上的 ⛶），全屏时书会撑到接近满屏高度。左右方向键翻页，手机上单页显示，可以左右滑。

## 关于字体

页面用的是系统里的楷体（macOS 的 Kaiti SC、Windows 的 KaiTi），没有楷体时退到宋体，再没有才退到通用衬线字体。所以在 Mac、iPhone、Windows 上是楷体；部分安卓和 Linux 机器上可能退成黑体，古意会打折。要在所有设备上都稳定显示楷体，需要自带一份字体文件，那是另一件事。
