# 绒草集

收词与散文。长短句与散记，写情、写日常、写说不清的东西。

```poetry
集名: 绒草集
副题: 词 · 散文
色: 赭
印: 绒
说明: 绒是软的，草是野的。不成体统的句子先放这里。

@ 无题
体裁: 散文
若夫烟华初歇，残雪微寒。客有泛舟于春江之浦，抚拂晓之青峦。宿雨初霁，四顾寂寥而无人语；迷雾未开，欲渡长川而失旧径。感前尘之不可追，怅流年之如逝水，乃倚篷独卧，听浪息心。

须臾心神相望，随江波摇曳，飘然游于太虚。忽见瑶台崔嵬，霞光万道；天阙洞开，仙乐齐鸣。有仙子凌波而至，赐霓裳以曼舞，动羽衣而轻扬。云袖回旋，若卷九天之星河；月华倾泻，尽照杯盏之琼浆。宾主尽欢，不知今夕何夕，极尽人世难求之绚烂。

俄而仙乐骤歇，清风惊梦。睁眼视之，广寒玉宇尽化虚无，唯余一叶扁舟，横于苍茫烟渚。残寒未褪，身披粗简之蓑衣；宿雾犹浓，极目唯见江天一色。方悟向者极乐盛景，不过浮生大梦一场；所谓执念前尘，亦如烟水无痕。

客遂哑然失笑。既知万象皆幻，何苦自缚忧思？乃启泥封，引浊酒，邀同舟之萍水过客，对饮江上。笑谈间宿怨尽释，长歌中万虑皆空。一任孤舟荡漾，随沧浪而去，自得浮生真意。
```

写法是在上面的代码块里以 `@ 题名` 起一篇，下面直接写正文；词可以标 `词牌`，散文、赋一类长文标上 `体裁` 之后会自动换成更适合长文的字号与行距。详见[诗词说明](README.md)。
