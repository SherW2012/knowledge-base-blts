# 本部

负责健康管理、健身目标、生活习惯、出行与日常系统，也负责个人行动准则与自我调度。

## 每日执行硬标准

最多同时推进两件核心事项。每天只设定两个核心目标，并以这两个目标是否完成作为当天的主要完成标准；其他事情全部降为次级优先级，是否完成不作为当天是否有效的判断依据。

## 核心人格系统

座右铭、行动准则、四重人格调度原则、五忌三议、潜龙模式和金鸡湖协定统一进入独立的「本部人格中枢」应用，不再作为独立 Markdown 文章展示。

「生辰八字」也放在这个应用里，只记排盘结果（四柱、十神、藏干、纳音、星运、五行分布、支间关系、大运）和起算口径，不写断语。流年与现行大运按当前日期实时算，不用手动改。
