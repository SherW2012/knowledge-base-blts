# 有趣的网站收藏

一些适合学习、游戏、怀旧、探索和摸鱼的网站，没事的时候可以慢慢逛。

## 1. Zoom Earth

https://zoom.earth

实时地球，可以看卫星云图、台风、降雨、火灾等全球动态。

## 2. YIKM 小霸王游戏机

https://yikm.net

在线玩超级玛丽、魂斗罗、坦克大战等经典老游戏。

## 3. The Deep Sea

https://neal.fun/deep-sea/

深海模拟器。一路向下滑，可以看到不同海洋深度生活着哪些生物。

## 4. 投胎模拟器

https://toutai.cc

根据人口统计数据模拟如果重新出生，可能会出生在哪里。

## 5. 老画报

https://laohuabao.com

收藏大量老连环画、小人书等内容，适合怀旧和随便翻看。

## 6. 全历史

https://allhistory.com

通过时间轴和人物关系把历史串起来，适合查历史事件、人物关系和各种冷知识。

## 分类速览

- 学习 / 探索：Zoom Earth、The Deep Sea、全历史
- 游戏：YIKM 小霸王游戏机
- 怀旧：老画报
- 随机体验 / 摸鱼：投胎模拟器
