# 把 AI 学习路径做成可执行课程

## 灵感来源

- [rohitg00/ai-engineering-from-scratch](https://github.com/rohitg00/ai-engineering-from-scratch)

这个项目的价值不只是“AI 学习资料很全”，而是它把学习本身做成了一套**可执行、可验证、可持续产出的工程系统**。

项目把 AI 工程拆成 20 个阶段、500+ 节课，并要求每节课都产出实际 artifact，例如 prompt、skill、agent、MCP server，而不是只读文档。它还进一步把学习流程封装成 Agent Skills，让 AI Tutor 负责定位起点、制定学习路径、逐课教学和测试。

## 真正值得借鉴的创意

**学习不再是“看教程”，而是“沿着一条工程流水线持续生产作品”。**

可以借鉴这个模式，为某个细分领域做自己的可执行课程：

1. 把一个领域拆成明确阶段和能力树。
2. 每一节只解决一个问题，并要求产出一个真实作品。
3. 每个作品都进入 GitHub，成为可展示、可复用的资产。
4. 用 Agent Skill 承担导师角色：测水平、安排下一课、验收结果、指出薄弱点。
5. 最终形成“学习路径 + Agent Tutor + 项目作品集”的完整产品。

## 可以延伸的方向

- 做一套面向普通人的「AI 副业工程」课程，而不是传统 AI 理论课程。
- 做一套「AI 内容创作者工程」课程：选题、搜索、写稿、配图、剪辑、分发、复盘，每节都交付一个可运行 Skill 或工作流。
- 做一套个人版 AI Engineering Roadmap，学习过程同时沉淀到知识库和 GitHub 项目中。
- 把公开学习过程同步做成 X / 小红书 / 视频内容，实现 **学习 → 项目 → 内容 → 流量 → 产品** 的闭环。

## 核心判断

未来好的教程可能不再是一堆文章或视频，而是一套**能被 Agent 执行的课程协议**：AI 知道你学到哪里、下一步做什么、产出什么、怎样验收。
