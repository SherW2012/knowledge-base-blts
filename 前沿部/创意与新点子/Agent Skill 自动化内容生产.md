# Agent Skill 自动化内容生产

## 创意点

把成熟的内容生产流程封装成可复用的 **Agent Skill**，让 Agent 不只是“给建议”，而是直接执行一整套标准化内容生产工作流。

这次发现的案例：
- [chengyi-ai/native-subtitle-quote-image](https://github.com/chengyi-ai/native-subtitle-quote-image)
- 能把视频处理成社交媒体可直接使用的字幕金句长图：定位台词 → 精确取帧 → 保留原生字幕 → 3:4 拼图 → 质检。

真正值得记录的不是这一个 Skill，而是这个方向：**把一个个成熟的内容生产动作封装成 Agent Skill，逐渐组成自己的自动化内容工厂。**

## 可继续探索

- 长视频自动找爆点 / 金句
- 自动生成字幕截图与小红书长图
- 自动拆稿、标题、封面、配图
- 多个 Skill 串联成完整内容流水线
- 搜集并测试 GitHub 上现成的优质 Agent Skills，能复用的不重复造轮子
