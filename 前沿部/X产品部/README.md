## X 情报雷达

执行“今天 X 情报 / 过去一天 X 情报 / 更新 X 雷达 / 扫今天值得发的内容”前，**必须完整读取 `X情报雷达固定情报源扫描手册.md`**。

这份文件是唯一的雷达执行 Prompt，统一规定：

**确定 24h 窗口 → 扫多源 → 时间过滤 → 一手核验 → 去重聚类 → 评分筛选 → 生成 archive/report → 覆盖 latest.json → Push → 等 GitHub Actions 完整部署成功 → 检查线上页面。**

不得只凭记忆执行，不得跳过固定流程，不得把普通科技新闻聚合冒充 X 情报雷达。

雷达选题优先追求：**网感、传播性、利他性、普通用户可接触性**。Skill、GitHub 小项目、实用工具、学习路径、AI 工作流、AI+股票/币圈新玩法、AI 赚钱与一人公司等用户能直接拿走的内容优先；高管离职、融资、收购、无用户体验提升的底层技术和纯论文默认降权。

研究由当前 ChatGPT 会话使用自身 Web 搜索与研究能力完成；禁止调用 DragonCode 或其他外部 LLM API 代替研究、筛选和判断。

完成研究后必须更新 `radar-data/latest.json`、对应日期 archive 和 report。GitHub Commit 不等于网页发布完成；只有 Actions 构建与 Pages deploy 成功，并实际检查线上页面显示当天数据后，才算完成。
