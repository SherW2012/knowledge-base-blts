# Knowledge Base

这是一个以 **Markdown + GitHub** 为底层的个人知识库。

核心原则：

- GitHub 仓库保存 Markdown 文档与真实目录结构。
- 图片、视频等大文件不直接放入仓库，优先上传到 R2 / 对象存储，并在 Markdown 中保留链接。
- Codex / ChatGPT 可以直接围绕仓库检索、整理、创建和更新文档。
- 不使用 Database / Relation 模拟目录，目录本身就是知识结构。

## 一级目录职责

- `本部/`：健康管理、健身目标、生活习惯与日常系统
- `外交部/`：个人成长、做人原则、心理模式、人际关系与人格体系
- `技术部/`：技术积累、软考、工程实践与技术壁垒
- `前沿部/`：AI 前沿、自媒体、内容选题、X、AI 变现，以及创意、新点子、新玩法和待验证方向
- `商务部/`：理财、股票、投资、商业研究、CFA
- `艺术部/`：审美、人像摄影、拍摄技巧与作品复盘

## 使用方式

新知识直接创建 `.md` 文件并放入对应目录。目录尽量保持在「部门 → 主题 → 文档」三层左右；只有确实需要时才继续增加子目录。

创意、新点子和尚未成熟的实验性方向统一归 `前沿部/创意与新点子/`。如果内容归属不明确，不使用“收件箱”兜底，先判断或询问后再归档。

当前仓库已设为 **Private**。仍应避免写入密码、Token、密钥、身份证件等高敏感凭据。
