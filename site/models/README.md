# 设备 3D 模型

把真实机型的 `.glb` 放进这个目录，然后在 `site/gear-data.json` 里把文件名填到那台设备的 `modelPath`，例如 `"modelPath": "./models/ricoh-gr3x.glb"`。

场景会自动做三件事：

1. 按 `dimensions`（毫米，宽 × 高 × 厚）等比缩放，让模型正好落进这个真实尺寸——模型自带什么单位、原点在哪都无所谓，不需要手工调 scale。比例本来就对的模型会精确贴合；比例不对的会以最保守的那一轴为准，不会被拉变形。
2. 把模型重新居中，底面贴桌、水平居中。
3. 加载失败时保留参数化生成的形体，不会白屏，也不会让整个场景崩掉。

没填 `modelPath` 的设备用参数化形体：按 `form` 和 `dimensions` 现场生成机身、镜头筒、转盘、屏幕，比例是真实的，可以先用着。

## 模型建议

- 格式 GLB / glTF 2.0，单个文件控制在 1.5MB 以内（11 台加起来别超过 15MB，否则首屏进不了 3 秒）
- 三角形 5k–60k 就够网页用，不需要 CAD 精度；保留外轮廓、镜头、按键、屏幕、转盘即可
- 贴图 1K–2K PBR（BaseColor / Normal / Roughness / Metallic），用 KTX2 或 WebP 压缩
- 朝向随意——脚本会重新居中，但**镜头最好朝 +Z、顶部朝 +Y**，这样聚焦时的机位角度最自然
