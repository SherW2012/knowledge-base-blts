# 软考知识库

本知识库按计算机学科主题组织，以Markdown文档承载，便于全文检索、持续补充、版本管理和网页浏览。

## 内容原则

- 知识条目按主题组织成系统性的说明文档，不使用零散问答或聊天记录结构。
- 图只用于解释单靠文字不容易看清的关系、流程、层次或状态，不为满足数量而重复画图。
- 空间结构、物理包含、复杂分层和多角色协作优先采用定制SVG；严格时序、状态迁移和简单步骤流程优先采用Mermaid。
- 图必须通过分组、位置、颜色、简短职责和必要连线承担解释任务，不能把“存在一张图”等同于“已经解释清楚”。
- 区分标准明确规定的事实、工程实现和帮助理解的解释。
- 涉及标准或规范时，以标准文本和明确采用的教材术语为准。
- 不为了维护既有结论而反向编造理由。
- 缩写存在歧义时明确标注，不擅自替换。
- 使用直接、具体的技术解释，不采用比喻替代定义。
- 详略得当：基础、常用、高频的知识点必须充分展开讲透，只有次要或边缘的内容才从简。

## 第一轮高频补洞（2026-08-26）

本轮不按教材目录一次性铺满，而是只补软考高频且当前明显缺失的支点：

1. 计算机性能指标与性能评价；
2. PV操作与进程同步；
3. 文件系统与索引文件；
4. 企业信息化与应用集成；
5. 需求工程；
6. 软件维护、逆向工程与遗留系统；
7. 项目管理基础；
8. UML核心图与关系；
9. 构件、中间件与ADL；
10. 软件可靠性基础与计算；
11. 嵌入式系统基础；
12. 著作权、商标与商业秘密。

后续继续采用“做题暴露缺口 → 判断是否高频 → 优先整合进现有文档 → 确有独立学习价值才新建页面”的方式扩充，避免再次出现单一章节一次性扩成完整教材的情况。
