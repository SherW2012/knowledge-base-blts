# 未来信息综合技术 · 本章导读

本章对应教程"未来信息综合技术"，以**人工智能与大模型**为核心深入展开（今年高频考点，作重点建设），其余新兴技术（云计算、大数据、物联网、区块链、边缘计算等）的概念要点随做题补充；其中云原生、大数据、面向服务另在下篇设有独立的架构实践章。

人工智能与大模型部分面向工程读者，系统讲清大语言模型与智能体（Agent）的底层机制和工程原理：模型如何工作、如何被调用、如何在循环中使用工具完成任务，以及围绕它的上下文、记忆、多智能体与 Harness 工程。

内容按由内到外的顺序组织，建议顺序阅读：

## 一、模型与推理

- [大语言模型的工作原理](01-大语言模型的工作原理.md)：分词、嵌入、Transformer 与自注意力、自回归生成、训练三阶段、能力与边界。
- [推理、采样与推理模型](02-推理、采样与推理模型.md)：logits 与温度、解码策略、幻觉的机制、推理模型与测试时计算、结构化输出。
- [LLM API 与 KV Cache](03-LLM-API与KV-Cache.md)：消息与角色、token 与上下文窗口、流式、KV Cache 与前缀/提示缓存、成本与延迟工程。

## 二、智能体机制

- [Agent 机制：Agent Loop 与 Tool Use](04-Agent机制：Agent-Loop与Tool-Use.md)：Agent 的构成、Agent Loop、工具调用协议、ReAct、Planning、停止与失败处理。
- [上下文工程与提示工程](05-上下文工程与提示工程.md)：上下文窗口作为工作内存、提示工程、上下文工程、长上下文失效、压缩与 System Prompt 设计。

## 三、工具、记忆与协作

- [工具、技能与 MCP](06-工具生态与MCP.md)：工具设计原则、技能（Skills）与渐进式披露、MCP 协议与架构、标准化的价值、安全边界。
- [记忆与检索：Memory、RAG 与 WebSearch](07-记忆与检索：Memory、RAG与WebSearch.md)：短期与长期记忆、向量检索、RAG 流程、Web Search 工具、检索质量。
- [Subagent 与多智能体系统](08-Subagent与多智能体系统.md)：上下文隔离、subagent、多智能体架构、协调机制与代价。
