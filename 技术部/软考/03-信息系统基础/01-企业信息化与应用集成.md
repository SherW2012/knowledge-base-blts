# 企业信息化与应用集成

## 1. 信息化相关题在考什么

这部分题目通常不是考某个企业软件的产品细节，而是考：不同信息系统分别服务什么业务、它们之间怎样集成，以及企业信息化从局部应用走向整体协同时常见的架构思路。

先建立总关系：

```text
企业业务
├── 面向内部资源：ERP
├── 面向客户关系：CRM
├── 面向供应链协同：SCM
├── 面向业务流程：BPM / 工作流
└── 面向系统之间打通：EAI / ESB / SOA
```

## 2. ERP

ERP（Enterprise Resource Planning，企业资源计划）强调把企业内部主要资源和业务流程纳入统一管理。

常见模块包括：

- 财务；
- 采购；
- 库存；
- 生产；
- 销售；
- 人力资源等。

ERP 的核心不是“做一个财务软件”，而是让不同部门基于相对统一的数据和业务流程协同。

## 3. CRM

CRM（Customer Relationship Management，客户关系管理）围绕客户全生命周期管理信息和业务活动。

常见内容：

- 客户资料；
- 销售机会；
- 营销活动；
- 服务记录；
- 客户价值分析。

判断题中看到“提高客户满意度、维护客户关系、分析客户价值、管理销售机会”，通常优先联想到 CRM。

## 4. SCM

SCM（Supply Chain Management，供应链管理）关注企业与供应商、制造、仓储、物流、渠道之间的协同。

它处理的范围通常跨越单个企业边界，例如：

```text
供应商 → 采购 → 生产 → 仓储 → 物流 → 经销商 → 客户
```

SCM 的典型目标包括降低库存、缩短交付周期、提高供应链响应速度和协同效率。

## 5. ERP、CRM、SCM 的区别

| 系统 | 主要关注对象 | 常见关键词 |
|---|---|---|
| ERP | 企业内部资源与流程 | 财务、生产、采购、库存、人力 |
| CRM | 客户关系 | 客户、销售机会、营销、服务 |
| SCM | 供应链上下游 | 供应商、物流、库存协同、交付 |

三者可以集成，但关注点不同。

## 6. 企业应用集成 EAI

企业中常常已经存在多个独立系统：ERP、CRM、财务、门户、旧业务系统等。如果每两个系统都单独开发接口，很容易形成复杂的点对点连接。

EAI（Enterprise Application Integration，企业应用集成）的目标是把这些异构应用连接起来，使数据和业务流程能够跨系统流动。

典型集成层次可以理解为：

- **数据集成**：共享或同步数据；
- **应用接口集成**：通过 API、消息等调用能力；
- **业务流程集成**：让一个流程跨多个系统执行；
- **门户/表示集成**：给用户提供统一入口。

## 7. 点对点集成与总线式集成

### 点对点

```text
A ↔ B
A ↔ C
A ↔ D
B ↔ C
...
```

系统少时简单直接，但系统数量增加后，接口数量和耦合关系迅速膨胀。

### 总线式集成

```text
A ─┐
B ─┼→ 集成总线 / 消息中间件 ← C、D、E
```

各系统通过公共集成机制通信，减少两两耦合。ESB（Enterprise Service Bus，企业服务总线）就是常见相关概念。

## 8. EAI 与 SOA

EAI 强调“把已有应用连接起来”；SOA 强调“把业务能力以服务形式组织并通过标准接口组合”。

两者经常结合：

```text
已有异构系统
      ↓
封装为服务 / 接口
      ↓
通过消息、中间件、ESB连接
      ↓
形成跨系统业务流程
```

更完整的 SOA、Web Service、REST 内容见[面向服务架构 SOA](../17-面向服务架构SOA/03-Web Service与SOA.md)。

## 9. 企业信息化方法

企业信息化不是简单“买软件”。一般要从业务目标、组织流程、信息资源、应用系统和技术基础设施共同考虑。

常见顺序可以概括为：

```text
企业战略与业务目标
        ↓
分析业务流程与信息需求
        ↓
规划信息系统和数据体系
        ↓
建设/集成应用系统
        ↓
持续运营、评价与改进
```

考试中若题目描述“先买工具，再寻找业务用途”，通常不是理想的信息化规划方式。系统建设应服务业务和组织目标。

## 10. 战略数据规划思想

信息系统规划常强调：数据相对稳定，业务处理过程更容易变化。因此在企业级规划中，不能只围绕当前某个应用程序组织数据，应重视跨业务共享的数据资源和统一数据模型。

这也是为什么大型企业会逐步建设主数据、数据仓库、数据平台等能力。

## 11. 电子商务的基本类型

常见分类按交易主体划分：

- **B2B**：企业对企业；
- **B2C**：企业对消费者；
- **C2C**：消费者对消费者；
- **C2B**：消费者向企业表达需求或提供价值。

考试重点一般是识别交易主体，不需要把商业模式展开成运营课程。

## 12. 做题识别法

看到关键词时可快速定位：

```text
客户关系、营销、销售机会 → CRM
供应商、物流、上下游协同 → SCM
财务生产采购库存统一 → ERP
异构系统打通、接口整合 → EAI
服务封装、松耦合、服务组合 → SOA
统一消息/集成总线 → ESB
```

## 核心关系

```text
ERP：管企业内部资源
CRM：管客户关系
SCM：管供应链上下游
EAI：把不同应用连接起来
SOA：把业务能力服务化并组合
ESB：一种常见的服务/消息集成基础设施
```
