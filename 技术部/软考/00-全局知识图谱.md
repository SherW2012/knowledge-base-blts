# 全局知识图谱

一张图涵盖**所有章节**。每个圆点是一个知识模块，颜色代表所属章节；连线表示模块之间的关系，**虚线橙色**是跨章节的联系（例如"存储层次 ↔ 分页存储""微服务 ↔ Web Service""加密算法 ↔ HTTPS"），帮助你看清整个知识体系怎么互相咬合。

暂无跳转的节点是尚未展开的知识点，之后会陆续补齐。

- **滚轮**缩放，拖动空白处**平移**，右上角可**全屏**
- **拖动任意节点**可自由摆布，其余节点会跟着牵动（松手后自动归位）
- **悬停**某个节点会高亮它的所有邻居
- 描边较粗的节点关联到具体文档，**点击即可跳转**
- 右上角可**重排 / 缩放 / 复位 / 全屏**；布局与视图位置会自动记住
