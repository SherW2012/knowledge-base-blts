# 著作权、商标与商业秘密

## 1. 这部分怎么考

软考里的知识产权题通常不是要求背完整法条，而是根据一个软件、文档、商标或企业资料场景判断：

- 哪种权利在保护它；
- 权利归谁；
- 哪些行为可能构成侵权；
- 保护期限和保护条件有什么基本差异。

需要先把几类权利分开：

```text
著作权：保护作品的表达
专利权：保护符合条件的技术方案
商标权：保护商品或服务来源标识
商业秘密：保护不公开且有商业价值的信息
```

专利部分见[专利权与职务发明](01-专利权与职务发明.md)。

## 2. 软件著作权保护什么

计算机软件通常包括程序和相关文档。著作权保护的是软件的**具体表达形式**，不是抽象思想、算法原理、数学方法或业务规则本身。

因此应区分：

```text
算法思想本身 ≠ 直接由著作权垄断
具体源代码/目标代码的表达 = 可以受到软件著作权保护
```

同一个功能由不同开发者独立使用不同代码实现，并不因为功能相同就必然构成著作权侵权。

## 3. 著作权自动产生

著作权通常在作品创作完成时产生，不以登记作为取得权利的必要条件。

软件著作权登记可以作为权属证明、交易和争议处理中的证据，但“未登记就没有著作权”这种说法不成立。

## 4. 人身权与财产权

著作权可以大体分为：

- 与作者身份、作品完整性等有关的人身权；
- 复制、发行、信息网络传播等具有经济利用价值的财产权。

考试更常从“谁有权复制、发布、许可、转让”角度考财产权归属。

## 5. 职务开发的软件

员工在履行工作职责或主要利用单位物质技术条件完成的软件，权利归属要根据具体法律规则、任务性质和约定判断。

软考题常出现的判断思路是：

- 是否属于本职工作任务；
- 是否主要使用单位资源；
- 单位与开发者是否有明确合同约定。

不要仅凭“代码是员工亲手写的”就认定全部权利一定属于个人。

## 6. 委托开发

委托开发的软件，著作权归属首先看合同约定。

没有明确约定时，应依据适用法律规定判断。考试题如果明确给出合同归属条款，应优先按约定分析。

这一类题的核心不是背某个案例，而是先找：

```text
有没有合同约定？
有没有职务关系？
作品是在什么任务背景下完成的？
```

## 7. 合理使用与侵权

著作权并不意味着任何使用都要获得许可，法律会规定合理使用等例外；但未经许可复制、传播或商业利用他人受保护的软件和文档，可能构成侵权。

常见风险行为：

- 复制并向他人提供未经授权的软件；
- 擅自上传、传播受保护作品；
- 抄袭他人软件代码或文档表达；
- 绕开许可范围进行超范围使用。

具体题目仍要结合权利状态、授权范围和法定例外判断。

## 8. 商标权

商标用于识别商品或服务来源，例如名称、图形、标志等。

商标权关注的是：消费者能否通过标识区分不同经营者的商品或服务。

因此它与著作权关注点不同：

```text
著作权：作品表达
商标权：商品/服务来源标识
```

一个图形 Logo 可能同时具有作品属性和商标属性，从而受到不同制度保护。

## 9. 注册商标

商标保护中常考注册、核定使用范围、续展和侵权判断等基础概念。

判断是否侵犯商标权时，通常会关注：

- 是否未经许可使用相同或近似标识；
- 商品或服务是否相同或类似；
- 是否容易导致相关公众混淆。

不是“只要两个名字有几个字相同就一定侵权”。

## 10. 商业秘密

商业秘密不是通过向社会公开来换取保护，而是依赖其**不公开状态**存在。

典型商业秘密可能包括：

- 源代码；
- 未公开算法实现；
- 客户名单；
- 价格策略；
- 工艺参数；
- 内部经营数据。

判断商业秘密通常抓三个核心特征：

1. 不为公众普遍知悉；
2. 具有商业价值；
3. 权利人采取了相应保密措施。

## 11. 保密措施

如果企业希望一份信息以商业秘密方式受到保护，就不能完全不做管理。

常见保密措施：

- 权限控制；
- 保密协议；
- 文档分级；
- 访问日志；
- 物理隔离或技术保护；
- 员工离职交接和保密要求。

商业秘密的重点之一是：**权利人自己也要表现出保护秘密的意图和措施。**

## 12. 商业秘密与专利的区别

二者保护策略几乎相反：

```text
专利：公开技术方案，换取法定期限内排他权
商业秘密：保持秘密，只要秘密状态持续且符合法定条件，就可能持续受到保护
```

适合反向工程、容易被公开产品推知的技术，长期依赖商业秘密保护可能存在较大风险；而某些难以从产品反推出的内部方法则可能适合保密。

## 13. 著作权与专利的区别

以软件为例：

- 著作权保护代码、文档等具体表达；
- 专利在满足专利条件时保护技术方案；
- 同一个软件项目可能同时涉及两种权利，但保护对象不同。

不能说“有软件著作权，所以其中所有算法思想都被独占”。

## 14. 做题快速识别

```text
源代码、文档表达被抄 → 著作权
技术方案、新发明 → 专利
品牌名称、Logo、商品来源混淆 → 商标
未公开客户名单、配方、内部算法 → 商业秘密
```

判断权属时：

```text
先看合同约定
再看是否职务开发/委托开发
再结合适用法律规则
```

## 15. 核心关系

```text
著作权：保护表达，通常创作完成即产生
商标权：保护识别商品/服务来源的标识
商业秘密：保护未公开、有价值且采取保密措施的信息
专利权：保护满足条件并依法取得权利的技术方案
```

> 本章用于软考知识点理解和题目辨析，不作为具体法律纠纷的法律意见。涉及现实争议时应以现行法律、司法解释和具体事实为准。
