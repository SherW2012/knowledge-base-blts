## 复盘格式与掌握状态

每道错题解析必须就地展示完整原题、所有选项和必要的共享材料，再列个人答案、正确答案、推理过程、各干扰项的错误原因及对应知识链接，不能只写题号后要求翻回试卷。

记录状态分为“答错待复测”“答对但靠猜／理由不确定”“已讲解待复测”“迁移复测通过”。答对不直接等同于掌握；只有能够解释依据并通过改变条件或任务的复测，才更新掌握状态。没有证据时，错因记录为待确认，不能凭答案排列推断作答动机。

复测保留原题记录，另附迁移题及结果，不能覆盖初次作答历史。作答阶段只展示试题；提交答案后再进行批改和错题归档。
