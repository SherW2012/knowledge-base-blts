# 英文阅读与完形填空

## 1. 题型特点

软考专业英语通常使用计算机技术短文，要求根据语法、固定搭配、上下文语义和专业知识选择合适词语。

常见主题包括：

- 软件工程与开发方法；
- 软件架构和设计模式；
- 操作系统与数据库；
- 计算机网络与信息安全；
- 人工智能、云计算和分布式系统；
- 项目管理与质量管理。

这类题同时检查英语阅读和专业概念，但多数空格不需要完整翻译全文才能判断。

## 2. 固定解题流程

```mermaid
flowchart LR
    A["快速通读<br/>确定技术主题"]
    B["观察空格结构<br/>判断词性和句法成分"]
    C["检查固定搭配<br/>介词、并列和常用表达"]
    D["结合上下文<br/>判断逻辑和语义"]
    E["利用专业知识<br/>排除概念错误"]
    F["代回全文<br/>检查语法和连贯性"]

    A --> B --> C --> D --> E --> F
```

推荐顺序：

1. 先快速通读，确定文章讨论什么技术；
2. 不急于逐词翻译，先观察每个空格前后的语法结构；
3. 判断空格需要名词、动词、形容词、副词、介词还是短语；
4. 检查并列结构、固定搭配和主谓一致；
5. 再使用专业知识判断哪个词符合技术含义；
6. 把选择代回原句和全文，检查是否自然、连贯。

## 3. 语法定位

### 词性

| 空格附近的结构 | 常见需要的成分 |
|---|---|
| `a/an/the + ___` | 名词，或“形容词 + 名词”中的形容词 |
| `be + ___` | 形容词、名词、过去分词或现在分词 |
| `to + ___` | 动词原形 |
| `by + ___` | 名词或动名词 |
| `modal verb + ___` | 动词原形 |
| `___ + noun` | 形容词、名词修饰语或限定词 |
| `verb + ___` | 名词、代词、副词或由该动词决定的结构 |

### 并列结构

`and`、`or`、`but`连接的成分通常具有相同语法层级：

```text
modular and ___ framework
```

`modular`是修饰`framework`的形容词，因此空格通常也需要能够与它并列、共同修饰`framework`的成分。

```text
by ___ and contributing their expertise
```

`contributing`是动名词，空格通常需要与它保持平行结构。

并列结构只能确定语法形式，最终词义仍需结合上下文和选项。

### 主谓一致和时态

应先找出真正主语：

```text
complex problems that ___ a well-defined algorithm
```

关系代词`that`指向复数`problems`，空格中的谓语形式需要与复数先行词保持一致。

## 4. 上下文关系

常见逻辑关系：

| 关系 | 常见提示词 |
|---|---|
| 原因与结果 | because, since, therefore, thus, result in |
| 转折 | but, however, although, while |
| 并列与递进 | and, also, furthermore, moreover |
| 条件 | if, unless, provided that |
| 举例 | for example, such as |
| 解释与改述 | that is, namely, in other words |
| 时间和顺序 | first, then, when, until, finally |

完形填空不能只看空格左右两三个词。代词指向、前后句重复的技术概念以及整段的因果关系都可能决定词义。

## 5. 专业知识怎样参与判断

专业知识用于排除“语法正确但技术含义错误”的表达，但专业概念本身由对应学科章节负责完整说明。

例如，阅读涉及Blackboard Architecture的文章时，英文章节只记录`decentralized`、`partial solution`、`knowledge source`等词义、词性和搭配；架构组成、工作过程、优缺点和概念辨析统一放在[软件体系结构风格](../09-系统架构设计基础/01-软件体系结构风格.md)的黑板架构小节中。

这种分工可以避免英语词库逐渐变成软件工程教程，也避免专业技术章节混入英语语法和记词方法。

## 6. 高频构词规律

掌握词根、前缀和后缀可以减少纯记忆量。

| 形式 | 常见作用 | 示例 |
|---|---|---|
| `-tion` / `-sion` | 名词 | definition, transmission |
| `-ity` | 性质名词 | availability, reliability |
| `-ment` | 名词 | development, requirement |
| `-able` / `-ible` | 能够……的 | reusable, compatible |
| `-ive` | 具有……性质的 | effective, collective |
| `-ly` | 副词 | effectively, typically |
| `inter-` | 在……之间 | interaction, interoperability |
| `pre-` | 预先 | predefined, predetermined |
| `re-` | 再次、返回 | recover, reuse |
| `un-` / `in-` | 否定 | unavailable, incomplete |

同一词族应成组记忆：

```text
define → definition → well-defined
rely → reliable → reliability
operate → operation → operational
interoperate → interoperable → interoperability
```

## 7. 词库记录规则

词库按照“技术主题 + 单词或短语 + 典型搭配”记录，不只保存孤立中文释义。

| 字段 | 记录内容 |
|---|---|
| 单词或短语 | 原文中的常用形式 |
| 词性 | 名词、动词、形容词、副词或固定短语 |
| 核心含义 | 在计算机专业语境中的常见中文含义 |
| 常见搭配 | 真实句子中经常共同出现的词 |
| 易混点 | 相似词、不同词性或常见误解 |
| 主题 | 软件工程、网络、数据库等分类 |

新增词汇时优先收录：

- 在软考文章中反复出现的词；
- 不认识会影响整句理解的专业词；
- 常用于固定搭配的普通学术词；
- 词性变化容易造成判断错误的词族；
- 中文意思接近但英文使用条件不同的词。

### 本组需要成组记忆的搭配


## 9. 最终检查

完成所有空格后逐项检查：

```text
词性是否正确
主谓是否一致
时态和语态是否一致
并列结构是否平行
固定搭配是否自然
代词指向是否明确
技术含义是否正确
整段逻辑是否连贯
```

如果两个选项在中文翻译上都说得通，优先比较英文固定搭配、句法结构和技术语境，而不是只比较中文释义。
