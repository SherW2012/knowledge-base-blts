# 架构师高频专业词汇

## 1. 这份词表怎么使用

专业英语题最有效的记法不是孤立背中文，而是把单词和对应技术概念绑定。看到英文后，应能直接跳到技术含义，而不是先逐字翻译整句。

本页持续收集模拟卷和真题中容易因为术语映射失分的词。技术原理仍以对应中文知识章节为准。

## 4. 三组最容易混的英文

### 4.1 2PL 与 2PC

```text
Two-Phase Locking  = 2PL = 两阶段锁协议
→ 数据库并发控制、冲突可串行化

Two-Phase Commit   = 2PC = 两阶段提交
→ 分布式事务、多个节点统一提交/回滚
```

### 4.2 availability 与 reliability

```text
availability：需要使用时能不能提供服务
reliability：在规定时间和条件下能不能持续正确运行
```

两者相关但不是同义词。冗余和故障切换经常直接提高availability。

### 4.3 stateless 与 state

```text
resource state：资源业务状态，可以保存在服务器数据库
session context：某客户端上一次交互到哪一步
```

REST的stateless要求后者不能成为处理当前请求所必需的隐藏服务器会话依赖，并不禁止服务器保存业务数据。

## 5. 词根辅助记忆

```text
available → availability
reliable → reliability
sensitive → sensitivity
state → stateless → statelessness
atom → atomic → atomicity
participate → participant / participating
prevent → prevention
detect → detection
trace → traceability
```

看到 `-ity` 通常可以优先考虑“某种性质、属性”的名词，例如availability、reliability、atomicity、sensitivity。
